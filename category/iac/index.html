🏗️ Terraform, Ansible & IaC

Infrastructure as code and configuration management.

  • ansible-galaxyManage Ansible roles/collections
  • ansible-inventoryShow inventory
  • ansible-lintLint playbooks
  • ansible-playbookRun Ansible playbooks to automate multi-host configuration.
  • ansible-vaultEncrypt Ansible secrets
  • cloud-initCloud instance initialisation

  • pulumiInfrastructure as code (general languages)

  • terraform fmtFormat configuration

  • terraform taintMark a resource for recreation
  • terraform validateValidate configuration
