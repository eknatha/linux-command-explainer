📁 Files & Archives

List, copy, move, search, compress and transfer files and directories.

  • basenameStrip directory from a path
  • bzip2Compress files with bzip2
  • catPrint or concatenate files
  • cdChange the current working directory.
  • chattrChange file attributes (immutable, append-only)
  • cmpCompare two files byte by byte
  • cpCopy files or directories from source to destination.
  • dfReport disk space usage of mounted filesystems.
  • dirnameStrip last component from a path
  • dirsShow the directory stack
  • duEstimate disk usage of files and directories.
  • fileDetermine file type by inspecting content (not extension).
  • findRecursively search for files by name, type, size, time, and more.
  • getfaclShow file access control lists
  • gunzipDecompress gzip files
  • gzipCompress or decompress files using the GNU zip DEFLATE algorithm.
  • installCopy files and set mode/owner
  • lnCreate hard or symbolic links between files.
  • locateFind files by name using an index
  • lsList directory contents with optional detail and sorting.
  • lsattrList file attributes
  • md5sumCompute or verify MD5 checksums
  • mkdirCreate one or more new directories.
  • mkfifoCreate a named pipe
  • mvMove or rename files and directories.
  • ncduInteractive disk usage browser
  • popdReturn to the previous directory on the stack
  • pushdPush a directory onto the stack and cd
  • pwdPrint the full absolute path of the current working directory.
  • readlinkResolve and display the target of a symbolic link.
  • realpathResolve a path to its absolute form
  • renameRename multiple files with a pattern
  • rmRemove files or directories permanently with no recycle bin.
  • rmdirRemove empty directories
  • rsyncFast, resumable file synchronization tool — local or over SSH.
  • scpSecurely copy files between local and remote hosts over SSH.
  • setfaclSet file access control lists
  • sha256sumCompute or verify SHA-256 checksums
  • shredOverwrite a file to make recovery harder
  • splitSplit a file into pieces
  • statDisplay detailed metadata about files and filesystems.
  • tarArchive and compress files — the standard Linux backup and packaging tool.
  • touchCreate an empty file or update timestamps
  • treeShow a directory tree
  • truncateShrink or extend a file to a size
  • unzipExtract ZIP archives
  • updatedbRebuild the locate database
  • xzHigh-ratio compression using the XZ/LZMA algorithm.
  • zcatPrint compressed file contents
  • zgrepSearch inside gzip files
  • zipCreate ZIP archives
  • zstdFast, modern compression with excellent speed/ratio trade-off.
