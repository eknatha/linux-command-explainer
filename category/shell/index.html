🐚 Shell & Scripting

Shell builtins, redirection, expansion, job control and scripting helpers.

  • aliasCreate shorthand names for commands or command sequences.
  • bashGNU Bourne-Again shell
  • bcArbitrary precision calculator
  • bgResume a job in the background
  • clearClear the terminal screen
  • commandRun a command bypassing functions/aliases
  • declareDeclare shell variables with types and attributes.
  • disownDetach a job from the shell
  • envPrint environment variables or run a command with a modified environment.
  • evalExecute a string as shell code
  • execReplace the shell with a command
  • exportSet environment variables available to child processes.
  • exprEvaluate expressions
  • falseExit with failure
  • fgBring a job to the foreground
  • getentQuery system databases
  • getoptsParse script options
  • historyDisplay or manipulate the shell command history.
  • jobsList background and stopped jobs in the current shell.
  • localDeclare a function-local variable
  • mapfileRead lines into an array
  • parallelExecute jobs in parallel from command line or files.
  • printenvPrint the value of specific environment variables.
  • readRead input from stdin or user prompt into shell variables.
  • screenTerminal multiplexer with persistent sessions (older alternative to tmux).
  • setSet shell options and positional parameters; control script safety.
  • shPOSIX shell
  • shiftShift positional parameters
  • sleepPause execution for a specified duration.
  • sourceExecute a script in the current shell context (no subshell).
  • sttyConfigure terminal line settings and fix broken terminals.
  • testEvaluate conditional expressions in shell scripts.
  • timeTime a command
  • timeoutRun a command with a time limit
  • tmuxTerminal multiplexer: manage multiple terminal sessions in one window.
  • tputQuery and initialize terminal capabilities for scripting.
  • trapExecute commands when the shell receives signals or exits.
  • trueExit with success
  • typeDescribe how a name is interpreted
  • unsetRemove a variable or function
  • waitWait for background jobs
  • whereisLocate binary, source, and man page for a command.
  • whichLocate the executable that would be run for a given command.
  • xdg-openOpen a file or URL with the default app
  • yesRepeat a string forever
