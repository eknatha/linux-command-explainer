apparmor (advanced)

Manage AppArmor mandatory access control profiles.

medium risk

medium riskDisabling profiles removes security enforcement.
⚠ Risks & cautions
  • Disabling a profile removes confinement — use aa-complain while debugging instead.
  • Profile syntax errors can stop services from starting; validate with apparmor_parser -p.
What it does

AppArmor confines processes to defined sets of files, capabilities, and network access using profiles. Default on Ubuntu/Debian. Profiles are stored in /etc/apparmor.d/. aa-status shows which processes are confined, aa-complain sets a profile to log-only mode for debugging.

Examples

aa-complain /etc/apparmor.d/usr.sbin.nginxSet nginx profile to complain/log mode for debugging · explain & risk-check →

Pro tip

Use `aa-complain` on a problematic profile, reproduce the issue, then check `dmesg | grep apparmor` to see exactly what was denied — build the policy fix from real denials, not guessing.
