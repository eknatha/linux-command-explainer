high riskInstalls/removes software as root; autoremove/purge delete data.
⚠ Risks & cautions
  • Simulate with -s first and read the “will be REMOVED” list.
  • `apt upgrade`/`full-upgrade` can restart services and replace kernels — schedule maintenance.
  • Don’t mix third-party repositories carelessly; pin versions in production.
  • Back up configs before purge.
Safer / dry-run alternatives
apt install -s <pkg>Simulate
apt-mark showholdCheck held packages
