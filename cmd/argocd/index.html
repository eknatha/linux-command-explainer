⚠ Risks & cautions
  • `argocd app sync` applies changes immediately (and --prune deletes resources not in Git).
  • Check `argocd app diff <app>` first.
  • Auto-sync with self-heal reverts manual cluster changes.
What it does

ArgoCD is a declarative GitOps CD tool for Kubernetes. It monitors Git repositories and ensures cluster state matches. The CLI manages applications, syncs state, and rolls back. Applications show as Synced/OutOfSync and Healthy/Degraded.

Examples

Pro tip

Use `argocd app diff` before every manual sync in production — it shows the exact Kubernetes resource changes, equivalent to `terraform plan` for your GitOps workflow.
