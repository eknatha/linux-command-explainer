auditctl

Control the Linux audit system

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskWrong rules can flood logs or, with -e 2, lock the audit configuration until reboot.
⚠ Risks & cautions
  • Rules that match busy paths can generate gigabytes of logs and fill /var.
  • -e 2 makes rules immutable until reboot.
  • -D removes all rules including compliance ones.
Safer / dry-run alternatives
auditctl -lReview existing rules first
What it does

Add, list and delete kernel audit rules.

Common flags
FlagMeaning
-lList rules
-wWatch a file
-DDelete all rules
-e 2Lock configuration (immutable until reboot)
