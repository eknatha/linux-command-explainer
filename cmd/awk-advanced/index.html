What it does

awk is a full programming language embedded in the shell pipeline. Beyond simple field printing, it supports BEGIN/END blocks for pre/post processing, associative arrays for aggregation, conditional logic, and arithmetic — replacing Python for many data processing tasks.

Common flags
FlagMeaning
-FSet field separator
-vSet variable before processing begins

Pro tip

Use `awk '{count[$1]++} END{for(k in count) print count[k], k}' | sort -rn` for instant frequency analysis of any column — replaces sort|uniq -c for multi-field grouping.
