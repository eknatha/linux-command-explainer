EC2 instances and networking

high riskterminate-instances deletes servers and their root disks.
⚠ Risks & cautions
  • terminate-instances cannot be undone — enable termination protection on critical hosts.
  • Opening 0.0.0.0/0 on SSH/RDP/DB ports is a common breach path.
  • Stopping instances loses ephemeral (instance-store) data and may change public IPs.
Safer / dry-run alternatives
aws ec2 <action> --dry-runValidate permissions without acting
aws ec2 create-snapshot --volume-id <vol>Snapshot before destructive changes
