high riskrm/sync --delete/rb remove objects irreversibly (unless versioning).
⚠ Risks & cautions
  • Use --dryrun first for sync/rm/mv.
  • sync --delete mirrors deletions — pointing the wrong way erases the destination.
  • Public ACLs/policies expose data: keep Block Public Access on.
  • Enable versioning + MFA delete for critical buckets.
Safer / dry-run alternatives
aws s3 sync <src> <dst> --dryrunPreview
aws s3api get-bucket-versioning --bucket <b>Check versioning
What it does

High-level S3 commands: ls, cp, mv, rm, sync, rb.

Common flags
FlagMeaning
lsList
cpCopy
syncSynchronise folders
rm --recursiveDelete many objects⚠ Irreversible without versioning.
--dryrun --dryrunShow what would happen
--delete --deleteRemove destination objects not in source⚠ Can wipe a bucket.
rb --forceRemove a bucket and contents⚠ Permanent.
