high riskActs on real cloud resources; the wrong profile/region affects the wrong account.
⚠ Risks & cautions
  • Always check account + region before changes (sts get-caller-identity).
  • Credentials in environment variables or ~/.aws/credentials grant everything the user can do — use SSO / short-lived roles.
  • Use --dry-run (EC2) and `aws s3 ... --dryrun` wherever available.
Safer / dry-run alternatives
aws sts get-caller-identityConfirm the account first
aws configure listCheck profile/region
What it does
