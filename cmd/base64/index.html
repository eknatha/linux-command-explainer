base64

Encode or decode data using Base64.

  • Base64 is encoding, not encryption — never treat it as protecting secrets.
What it does

base64 encodes binary data as printable ASCII text, or decodes it back. Used in Kubernetes secrets, JWT tokens, basic auth headers, and embedding binary data in text formats. Note: base64 is encoding, not encryption — encoded data is trivially reversible.

Common flags
FlagMeaning
-d --decodeDecode Base64 input
-w --wrapWrap encoded lines at N characters (0 to disable)
Examples

kubectl get secret mysecret -o jsonpath='{.data.password}' | base64 -dDecode a Kubernetes secret value · explain & risk-check →
cat cert.pem | base64 -w 0Base64 encode certificate without line wraps · explain & risk-check →
Pro tip

Use `echo -n` (no newline) before piping to base64 — without -n, the newline character is included in the encoding and your decoded value will have a trailing newline.
