$ 
medium riskRuns arbitrary commands; scripts execute with your privileges.
⚠ Risks & cautions
  • `curl … | bash` executes unseen remote code — download, read, then run.
  • Without `set -euo pipefail`, scripts continue after errors and can do damage with empty variables.
What it does

The default shell on most Linux systems. `bash -c` runs a string as a command; `bash script.sh` runs a script.

Common flags
FlagMeaning
-cRun a command string
-xTrace commands as they run
-nSyntax check without running
-eExit on first error
-uTreat unset variables as errors
-lLogin shell
