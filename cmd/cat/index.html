cat

Print or concatenate files

low riskRead-only, but can dump secrets or binary data to the terminal.
⚠ Risks & cautions
  • `cat > file` and `cat file > file` overwrite or truncate files — `cat a b > a` destroys a.
  • Avoid cat on binary files; it can corrupt your terminal (use `reset` to recover). Use less or strings instead.
  • Do not cat files containing secrets in shared terminals or recorded sessions.
What it does

Concatenates files to standard output. Also used to create small files with redirection.

Common flags
FlagMeaning
