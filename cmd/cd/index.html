cd

Change the current working directory.

low risk

low riskNavigation only, no file modifications.
What it does

cd updates the shell's working directory. `cd -` returns to the previous directory. `cd ~` always goes home. In scripts, always pair cd with `|| exit 1` to catch failure before running destructive follow-up commands.

Examples

Pro tip

Use `pushd /path` and `popd` when you need a directory stack — navigate away and return without remembering the original path.
