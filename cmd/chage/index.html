Manage password aging

medium riskWrong expiry values can lock accounts.
⚠ Risks & cautions
  • -E0 expires the account immediately — useful for locking, but easy to do by accident.
  • Service accounts with max age set can fail unexpectedly.
What it does

Shows or changes password expiry policy per user.

Common flags
FlagMeaning
-lList aging info
-EAccount expiry date (-E0 expires now)
-MMaximum password age
-dSet last password change date
Examples
chage -l aliceShow policy · explain & risk-check →
