chmod

Change file or directory permissions.

high riskIncorrect permissions can expose files or break applications.
⚠ Risks & cautions
  • Avoid `chmod -R 777` — it makes everything world-writable and is almost never the real fix.
  • Recursive changes treat files and directories alike; use capital X or `find -type d`/`-type f` separately.
  • Find the real cause of “permission denied” with `namei -l <path>`.
Safer / dry-run alternatives
stat -c '%a %U:%G %n' <path>Record the current mode/owner.
chmod -R u=rwX,g=rX,o= <dir>Capital X sets execute only on directories and already-executable files.
What it does

chmod modifies read/write/execute permissions for owner, group, and others. Accepts symbolic (u+x) or octal (755) notation. Octal is precise and unambiguous — 755 means owner rwx, group r-x, others r-x. The -R flag applies changes recursively.

Common flags
FlagMeaning
-R --recursiveApply changes recursively to directories
-v --verbosePrint a message for each changed file
-c --changesReport only files that are changed

Pro tip

Remember '7=rwx, 6=rw-, 5=r-x, 4=r--'. Use 644 for files, 755 for directories as baseline public defaults — and 600/700 for anything private.
