comm

Compare two sorted files line by line

low riskRead-only; inputs must be sorted.
What it does

Shows lines unique to each file and lines common to both.

Common flags
FlagMeaning
-12Show only common lines
-23Show lines only in file 1
Examples
comm -23 <(sort a) <(sort b)Lines in a but not in b · explain & risk-check →
