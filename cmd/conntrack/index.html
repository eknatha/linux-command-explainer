⚠ Risks & cautions
  • Deleting entries (-D, -F) drops existing sessions — NAT’d connections break.
  • Use filters to target only the entries you need.
What it does

conntrack tools interact with the netfilter connection tracking subsystem — the table that tracks established connections for stateful firewalling. Used to monitor active connections, debug firewall issues, and force-expire stuck connection entries.

Common flags
FlagMeaning
-L --dumpList all tracked connections
-D --deleteDelete matching connections
-E --eventStream connection events in real time
-s --sourceFilter by source address

Pro tip

Watch `cat /proc/sys/net/netfilter/nf_conntrack_count` vs `nf_conntrack_max` — when count approaches max, new connections are silently dropped. Increase `sysctl net.netfilter.nf_conntrack_max` to fix.
