cp

Copy files or directories from source to destination.

medium risk

medium riskCan silently overwrite destination files without warning.
⚠ Risks & cautions
  • Silently overwrites existing files — use -i (ask) or -n (never).
  • With -r, a trailing slash or an existing destination changes where things end up; check with ls afterwards.
  • Permissions, ownership and timestamps are only preserved with -a / -p.
What it does

cp copies files and directories. Without -r it refuses to copy directories. -p preserves timestamps and permissions — critical for backups. -u only copies when source is newer. The -i flag adds interactive prompts before overwriting.

Common flags
FlagMeaning
-r --recursiveCopy directories and all their contents recursively
-p --preservePreserve timestamps, permissions, and ownership
-i --interactivePrompt before overwriting existing files
-u --updateCopy only when source is newer than destination
-v --verbosePrint each file as it is copied
-a --archiveSame as -dR --preserve=all — full archive copy

Pro tip

Prefer `rsync -a` over `cp -r` for large directories — rsync is resumable, shows progress, and handles edge cases better.
