crontab

View, edit, or manage per-user cron schedules for recurring jobs.

⚠ Risks & cautions
  • `crontab -r` deletes ALL jobs without asking — and sits right next to -e on the keyboard.
  • Cron has a minimal environment (PATH, HOME); use absolute paths and redirect output.
  • Overlapping runs pile up — wrap jobs in `flock -n`.
What it does

crontab manages scheduled jobs. The five time fields are: minute (0-59), hour (0-23), day (1-31), month (1-12), weekday (0-7). `*` means any, `,` for lists, `-` for ranges, `/` for intervals. Always use full paths in cron commands.

Common flags
FlagMeaning
-eEdit current user's crontab in $EDITOR
-lList current crontab
-rRemove current user's crontab entirely
-uSpecify another user (root only)
