What it does

Beyond basic downloads, curl supports all HTTP methods, custom headers, authentication, JSON bodies, and detailed timing breakdowns. The -w format flag extracts timing metrics making curl a powerful HTTP performance testing tool.

Common flags
FlagMeaning
-X --requestHTTP method (GET, POST, PUT, DELETE, PATCH)
-H --headerAdd request header
-d --dataRequest body
-u --userBasic auth user:password
-k --insecureSkip TLS verification
-w --write-outOutput format for response metrics
-s --silentSuppress progress meter
-o --outputWrite response to file

Pro tip

Use `curl -w '%{time_namelookup} %{time_connect} %{time_starttransfer} %{time_total}\n' -so /dev/null URL` to break down DNS, TCP connect, and TTFB — pinpoints exactly where latency occurs.
