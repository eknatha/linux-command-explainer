low riskRead-only by default; piping responses to shell can execute arbitrary code.
⚠ Risks & cautions
  • `curl … | sh` runs unseen remote code — download, read, then run.
  • -k/--insecure disables TLS verification; -u user:pass puts credentials in history and the process list.
What it does

curl is the Swiss Army knife for HTTP. -I sends HEAD request (headers only). -o saves to file. -s enables silent mode. -X sets the HTTP method. Essential for API testing, downloading files, and debugging web requests.

Common flags
FlagMeaning
-I --headFetch HTTP headers only (HEAD request)
-o --outputWrite output to a file
-L --locationFollow HTTP redirects
-s --silentSilent mode — no progress bar
-X --requestSpecify HTTP method (GET, POST, PUT, DELETE)
-H --headerAdd a custom HTTP header
-d --dataSend POST body data
-k --insecureSkip SSL certificate verification (testing only)

Pro tip

Check HTTP status codes in scripts: `curl -w '\n%{http_code}' -s -o /dev/null https://url` — no download, just the status.
