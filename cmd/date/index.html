date

Display or set the system date and time; format timestamps.

⚠ Risks & cautions
  • `date -s` changes the system clock — it can break TLS, Kerberos, cron, logs and replication; use NTP/chrony instead.
What it does

date displays the current date/time in configurable formats, or sets the system clock. Heavily used in scripts for generating timestamps, log filenames, and date arithmetic. The -d flag parses arbitrary date expressions.

Common flags
FlagMeaning
-d --dateDisplay the given date string
-u --utcUse UTC time
+FORMATCustom output format

Pro tip

Use `date +%s` and arithmetic for measuring script execution time: `start=$(date +%s); ... ; echo $(($(date +%s)-start))s elapsed`
