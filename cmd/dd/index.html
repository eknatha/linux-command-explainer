dd

Convert and copy raw data

high riskWriting to the wrong target overwrites disks irrecoverably; there is no confirmation.
⚠ Risks & cautions
  • Swapping if= and of= overwrites your source.
  • Triple-check of=/dev/sdX with lsblk -o NAME,SIZE,MODEL,MOUNTPOINT.
  • Never write to a mounted disk or a device with unknown contents.
  • Nothing is asked: the first block is overwritten immediately.
Safer / dry-run alternatives
lsblk -o NAME,SIZE,MODEL,MOUNTPOINTVerify the target device
ddrescue <src> <dst> mapUse ddrescue for failing disks
pv file.iso | dd of=/dev/sdX bs=4MShow progress via pv
What it does

Copies blocks from input to output — used for disk images, boot media and benchmarking.

Common flags
FlagMeaning
if=Input file/device
of=Output file/device (DANGEROUS)⚠ A wrong of= overwrites data with no prompt.
bs=Block size
status=progressShow progress
conv=fsyncFlush data before exit
count=Number of blocks
Examples
dd if=/dev/sda of=disk.img bs=4M status=progressImage a disk · explain & risk-check →
