ddrescue

Rescue data from failing disks

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskWrites an image; wrong output target overwrites data.
⚠ Risks & cautions
  • Always write to a different disk with enough space.
  • Never run on a mounted failing disk if you can avoid it.
What it does

GNU ddrescue copies data from failing drives while keeping a map of bad areas.

Common flags
FlagMeaning
-nSkip the scraping phase
-rRetry count
-dDirect disc access
