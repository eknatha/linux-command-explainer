declare

Declare shell variables with types and attributes.

low risk

low riskScoped to current shell; -x exports to environment.
What it does

declare sets variable attributes: -i for integers, -a for arrays, -A for associative arrays (hash maps), -r for read-only, -x for export. Enables type-checking and structured data in bash scripts.

Common flags
FlagMeaning
-i --integerTreat variable as integer (arithmetic only)
-a --arrayIndexed array
-A --assocAssociative array (hash map)
-r --readonlyRead-only variable
-x --exportExport to environment
-p --printPrint variable declaration
Examples

Pro tip

Use `declare -A` for config maps in bash scripts: store key-value pairs without external tools. Iterate with `for key in "${!map[@]}"; do echo "$key=${map[$key]}"; done`
