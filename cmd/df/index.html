df

Report disk space usage of mounted filesystems.

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskRead-only filesystem inspection.
What it does

df shows disk space for each filesystem. -h makes sizes human-readable. -T shows the filesystem type (ext4, xfs, tmpfs). Filter with grep to exclude tmpfs mounts in containers which can clutter output.

Common flags
FlagMeaning
-h --human-readableShow sizes in K, M, G, T
-T --print-typeShow filesystem type
-i --inodesShow inode usage instead of block usage
--totalShow a grand total row
Examples
df -hT | grep -v tmpfsShow real disk usage excluding temporary filesystems · explain & risk-check →
df -i /Check inode usage on root — exhaustion prevents new files even with free space · explain & risk-check →
df -h --totalAll filesystem usage with a total summary line · explain & risk-check →
Pro tip

A disk can show free space but give 'No space left on device' — always check inodes with `df -i` too.
