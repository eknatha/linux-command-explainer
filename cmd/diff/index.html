What it does

diff compares two files and outputs the differences in a format that can be applied as a patch. The -u flag produces unified diff format (the standard for patches and code review). Useful for config auditing, reviewing changes before applying, and generating patches.

Common flags
FlagMeaning
-u --unifiedUnified diff format (standard for patches)
-r --recursiveCompare directories recursively
-i --ignore-caseIgnore case differences
-w --ignore-all-spaceIgnore all whitespace differences
-q --briefReport only whether files differ

Pro tip

Use `diff <(command1) <(command2)` with process substitution to compare command outputs without creating temp files — works for comparing live config with desired state.
