dig

Query DNS servers for records and debug DNS resolution.

⚠ Risks & cautions
  • Querying external DNS servers from production can leak internal hostnames; use `+short` and the right resolver (@server).
What it does

dig (domain information groper) queries DNS servers and displays detailed responses including record type, TTL, and which server responded. The go-to tool for DNS debugging — far more informative than nslookup.

Common flags
FlagMeaning
+shortPrint only the answer, no headers
+noall +answerShow only the answer section
@serverQuery a specific DNS server
-xReverse DNS lookup
-tSpecify record type (A, AAAA, MX, TXT, NS, CNAME, SOA)

dig +trace eknathalabs.comFull DNS resolution chain from root · explain & risk-check →
Pro tip

Use `dig +trace` to follow the full resolution path from root servers — reveals exactly which DNS server is serving stale or incorrect records during a propagation issue.
