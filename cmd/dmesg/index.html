  • Kernel logs can reveal addresses and hardware details; on some systems reading them requires root or kernel.dmesg_restrict=0.
What it does

dmesg displays kernel messages from the ring buffer — hardware detection, driver errors, disk issues, OOM killer events, and network events. The -T flag adds human-readable timestamps. Essential for diagnosing hardware failures, OOM events, and kernel panics.

Common flags
FlagMeaning
-T --ctimeHuman-readable timestamps
-l --levelFilter by level (err, warn, info, etc.)
-f --facilityFilter by facility (kern, daemon, etc.)
-w --followFollow kernel messages in real time
--clearClear the ring buffer (requires root)

Pro tip

After any unexplained process death, run `dmesg -T | grep -i killed` to check if the OOM killer was responsible — a common cause misdiagnosed as application bugs.
