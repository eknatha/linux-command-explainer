high risk`down -v` deletes volumes; the wrong project/directory affects the wrong stack.
⚠ Risks & cautions
  • `down -v` or `rm -v` deletes named volumes — data loss.
  • Check the directory and project name (-p); the same service names exist in many stacks.
  • `up` recreates containers when images or config changed.
Safer / dry-run alternatives
docker-compose configValidate and view the resolved config
docker-compose downWithout -v to keep data
What it does

Compose v1 binary; use `docker compose` (v2) today. Reads docker-compose.yml.
