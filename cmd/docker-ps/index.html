docker ps

List running (or all) Docker containers.

What it does

docker ps lists containers with their ID, image, command, status, and ports. The -a flag includes stopped containers. Combined with format strings, it produces machine-parseable output for automation.

Common flags
FlagMeaning
-a --allShow all containers (not just running)
-q --quietOnly show container IDs
--formatCustom output format template
-f --filterFilter by condition (e.g., status=exited)
Examples

Pro tip

Use `docker ps --format '{{.Names}}'` to get container names for scripting — far cleaner than parsing default tabular output with awk.
