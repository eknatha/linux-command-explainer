docker run

Run a container

high riskContainers can mount host paths, use host networking or run privileged.
⚠ Risks & cautions
  • --privileged, -v /:/host and -v /var/run/docker.sock grant host-level control.
  • Pin image tags/digests; avoid :latest.
  • Don’t pass secrets with -e — use secrets or env files with strict permissions.
  • Run as non-root (--user) and drop capabilities (--cap-drop ALL).
Safer / dry-run alternatives
docker run --rm --read-only --cap-drop ALL --security-opt no-new-privileges <image>Hardened run options
What it does

Creates and starts a container from an image.
