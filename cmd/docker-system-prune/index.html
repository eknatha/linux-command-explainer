docker system prune

Remove unused Docker data

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskDeletes stopped containers, unused networks, dangling images; with -a --volumes also unused images and volumes.
⚠ Risks & cautions
  • "Unused" means not referenced by a running container — stopped databases’ volumes can be deleted with --volumes.
  • -f skips the confirmation prompt.
Safer / dry-run alternatives
docker system dfCheck usage first
docker image pruneDangling images only
docker container pruneStopped containers only
What it does

Cleans up disk space used by Docker. See the flags and examples below, and run `man docker` for the full reference.

Common flags
FlagMeaning
-aRemove all unused images⚠ Forces re-pulls.
--volumes --volumesAlso prune volumes⚠ Deletes data in unused volumes.
-fDo not ask
