high risk`rm`/`prune` permanently delete data.
⚠ Risks & cautions
  • Volume data is not backed up by default.
  • prune deletes volumes not currently used by a container — including those of stopped databases.
Safer / dry-run alternatives
docker run --rm -v <vol>:/data -v $PWD:/backup alpine tar czf /backup/vol.tgz /dataBack up a volume first
What it does

Create, list and remove volumes. See the flags and examples below, and run `man docker` for the full reference.
