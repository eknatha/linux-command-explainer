Convert Windows line endings

⚠ Risks & cautions
  • Modifies files in place — use -n or keep a copy under version control.
  • Running it on binary files corrupts them (the tool normally skips them).
What it does

Converts CRLF to LF (and unix2dos does the reverse). Fixes “bad interpreter: ^M” errors in scripts.

Common flags
FlagMeaning
