du

Estimate disk usage of files and directories.

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskRead-only — scans disk usage without modifications.
⚠ Risks & cautions
  • Scanning huge trees (e.g. / or network mounts) causes heavy I/O — scope the path and use -x to stay on one filesystem.
What it does

du walks the directory tree summing file sizes. -s gives a total for each argument. --max-depth limits recursion depth. Piping to `sort -rh` reveals the biggest disk consumers — essential for tracking down space hogs.

Common flags
FlagMeaning
-h --human-readablePrint sizes in human-readable format
-s --summarizeDisplay only a total for each argument
-a --allInclude all files, not just directories
--max-depthLimit directory recursion depth
--excludeExclude files matching a pattern
Examples
du -sh /var/log/*Show size of each item in /var/log · explain & risk-check →
du -h --max-depth=2 / | sort -rh | head -20Find top 20 largest directories from root · explain & risk-check →
du -sh --exclude='.git' .Get total size of current directory excluding .git · explain & risk-check →
