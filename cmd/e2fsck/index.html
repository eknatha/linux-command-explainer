e2fsck

Check ext2/3/4 filesystems

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskRunning fsck on a mounted filesystem can corrupt it; repairs can delete data.
⚠ Risks & cautions
  • Never run on a mounted filesystem (except -n).
  • Take an image backup (dd/ddrescue) of failing disks before repairing.
  • Repairs can move data to lost+found.
Safer / dry-run alternatives
e2fsck -n <device>Read-only check first
ddrescue <device> image.img mapImage a failing disk first
What it does

Checks and repairs ext filesystems. Always run on unmounted devices.

Common flags
FlagMeaning
-nRead-only check
-pAutomatic safe repairs
-fForce check
-yAnswer yes to all repairs⚠ May delete or truncate damaged files.
