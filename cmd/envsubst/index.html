envsubst

Substitute environment variables in text

medium risk

medium riskCan expand secrets into output files and logs.
⚠ Risks & cautions
  • Unlisted variables become empty strings silently — restrict substitution to a variable list.
  • Rendered files may contain secrets; protect their permissions.
What it does

Replaces $VAR placeholders in a template with environment values — common in config rendering.

Common flags
FlagMeaning
$VARSLimit substitution to listed variables (argument)
