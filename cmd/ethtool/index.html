ethtool

Query and control network driver and hardware settings.

medium risk

medium riskChanging settings on live NICs can cause network disruption.
⚠ Risks & cautions
  • Changing speed/duplex/offload or ring settings on a live NIC can drop connectivity.
  • Settings are not persistent; apply via NetworkManager/udev once verified.
  • Never force speed/duplex on only one side of a link.
What it does

ethtool queries and configures Ethernet device settings: link speed, duplex, offload features, driver info, and statistics. Essential for NIC performance tuning, diagnosing link issues, and verifying network card capabilities.

Common flags
FlagMeaning
-i --driverShow driver info for a device
-S --statisticsShow NIC statistics
-k --show-featuresShow offload features
-K --featuresEnable/disable offload features

Pro tip

Run `ethtool -S eth0 | grep -i 'drop\|error'` when diagnosing packet loss — NIC-level drops are invisible to application-level monitoring and often missed.
