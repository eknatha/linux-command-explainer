exec

Replace the shell with a command

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskReplaces the current process; the session ends when the command exits.
⚠ Risks & cautions
  • Typing exec in an interactive shell with a command that exits closes your SSH session.
What it does

`exec cmd` runs cmd in place of the shell. `exec >file` redirects the whole script’s output.

Examples
