export

Set environment variables available to child processes.

low risk

low riskScoped to current session unless written to shell config.
⚠ Risks & cautions
  • Exporting secrets puts them in the environment of every child process and (if typed) into shell history — prefer reading them from a file or a secrets manager.
What it does

export marks a shell variable for export to the environment of child processes. Without export, variables are local to the current shell only. Used extensively in CI/CD pipelines, Docker, and application configuration. export -p lists all exported variables.

Common flags
FlagMeaning
-p --printPrint all exported variables
-n --unexportRemove variable from export list (don't delete it)
-f --functionExport shell functions

Pro tip

Use `export -p > session_vars.sh` to snapshot your current environment — useful before entering a complex debugging session.
