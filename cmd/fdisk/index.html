high riskWriting a partition table can destroy all data on the disk.
⚠ Risks & cautions
  • Identify the right disk with lsblk and serial numbers before editing.
  • Nothing is written until w; q quits without saving.
  • Deleting a partition makes its data unrecoverable without special tools.
  • Back up the partition table first: sfdisk -d /dev/sdX > sdX.pt
Safer / dry-run alternatives
sfdisk -d /dev/sdX > sdX.ptBack up the partition table
lsblk -fVerify which device is which
What it does

Interactive tool to create/delete partitions on MBR/GPT disks. Changes are written only when you press w.
