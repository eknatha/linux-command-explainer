file

Determine file type by inspecting content (not extension).

What it does

file tests files and reports their type based on magic bytes in the content, not the filename extension. Crucial for identifying mislabeled files, checking if a binary is ELF/ARM/x86, verifying compressed archives, and examining unknown files safely.

Common flags

Pro tip

Use `file` before executing or extracting unknown files — it reveals if a '.jpg' is actually a shell script or if a binary was compiled for the wrong architecture.
