find

Recursively search for files by name, type, size, time, and more.

⚠ Risks & cautions
  • Always run with -print first; only add -delete or -exec rm once the list is right.
  • -delete must be the LAST expression — tests placed after it do not limit what is deleted.
  • Searching / is slow and loads production disks; scope the path and add -xdev.
What it does

find is the most powerful file search tool on Linux. It supports filtering by name, type, permissions, size, modification time, and more — and can execute arbitrary commands on matches with -exec. Essential for cleanup, auditing, and automation.

Common flags
FlagMeaning
-nameMatch by filename (case-sensitive)
-inameMatch by filename (case-insensitive)
-typeFilter by type: f (file), d (dir), l (symlink)
-mtimeMatch by modification time in days
-sizeMatch by size (e.g., +100M)
-execExecute command on each match
-maxdepthLimit recursion depth

Pro tip

Use `-exec cmd {} +` instead of `-exec cmd {} \;` — the `+` variant batches arguments (like xargs), dramatically faster for large result sets.
