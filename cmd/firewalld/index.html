⚠ Risks & cautions
  • Without --permanent a change vanishes on reload; with --permanent it only applies after --reload — a mistake can surface later.
  • --panic-on drops all traffic including your SSH session.
  • Zones decide which rules apply — check the interface’s zone (--get-active-zones).
Safer / dry-run alternatives
firewall-cmd --list-allReview the active configuration first.

What it does

firewalld is the default firewall management tool on RHEL/CentOS/Fedora and their derivatives. It organizes rules into zones (public, trusted, internal, dmz) and uses services/ports instead of raw iptables chains. Changes with --permanent persist across reboots; without it, changes are runtime-only.

Common flags
FlagMeaning
--zoneTarget zone (default: active zone)
--permanentMake change persistent (survives reboot)
--runtime-to-permanentSave all runtime rules to permanent
--reloadReload permanent rules into runtime
--list-allList all settings for a zone

Pro tip

Always pair `--permanent` with `--reload` in a single operation — setting permanent without reload leaves runtime unchanged, leading to a 'why didn't my rule apply?' confusion.
