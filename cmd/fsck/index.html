fsck

Check and repair filesystems

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskRepairs can delete or relocate data; running on a mounted filesystem corrupts it.
⚠ Risks & cautions
  • Unmount first (or boot rescue mode).
  • -y can discard data automatically.
  • Image a failing disk before running repairs.
Safer / dry-run alternatives
fsck -n <device>Dry run
What it does

Front-end for filesystem checkers (fsck.ext4, fsck.xfs …).

Common flags
FlagMeaning
-nDo not make changes
-yAssume yes to all prompts
-fForce
-ACheck all in fstab
