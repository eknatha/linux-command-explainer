What it does

Manages local branches. See the flags and examples below, and run `man git` for the full reference.

Common flags
FlagMeaning
-aAll branches
-vvVerbose with upstream
-dDelete (merged only)
-DForce delete⚠ Loses unmerged commits (recoverable via reflog).
-mRename
