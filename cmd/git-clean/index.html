⚠ Risks & cautions

What it does

Removes files not tracked by git. See the flags and examples below, and run `man git` for the full reference.

Common flags
FlagMeaning
-nDry run
-fForce (required)⚠ Deletes files.
-dInclude directories
-xInclude ignored files⚠ Deletes .env, build output, local config.
