low riskLocal only until pushed.
⚠ Risks & cautions
  • Never commit secrets — rotate any key that was committed even if you remove it later.
  • --amend on pushed commits requires a force push.
  • --no-verify skips pre-commit/security hooks.
What it does

Creates a commit from the index. See the flags and examples below, and run `man git` for the full reference.
