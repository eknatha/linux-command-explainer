high riskPublishes changes; --force can overwrite others’ commits.
⚠ Risks & cautions
  • Check `git remote -v` and the branch before pushing.
  • Never force-push shared branches (main, release).
  • --delete removes a remote branch for everyone.
  • Pushed secrets are public history — rotate them.
Safer / dry-run alternatives
git push --force-with-leaseInstead of --force
git push --dry-runPreview what would be pushed
What it does

Sends local commits to a remote branch. See the flags and examples below, and run `man git` for the full reference.
