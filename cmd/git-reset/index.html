high risk--hard permanently discards uncommitted work; resetting pushed history needs a force push.
⚠ Risks & cautions
  • `git reset --hard` deletes uncommitted modifications with no recovery.
  • Resetting shared branches rewrites history for everyone.
  • Recover lost commits with `git reflog` (within ~90 days).
Safer / dry-run alternatives
git stash push -u -m "backup"Stash before a hard reset
git reset --soft HEAD~1Keeps your changes
git revert <commit>Safe for pushed commits
What it does

Moves the current branch to another commit; --soft keeps changes staged, --mixed unstages, --hard discards.

Common flags
FlagMeaning
--soft --softKeep changes staged
--mixed --mixedKeep changes unstaged (default)
--hard --hardDiscard all changes⚠ Uncommitted work is lost permanently.
