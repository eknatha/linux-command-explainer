git stash

Temporarily save and restore uncommitted work.

low risk

low riskStashes can be accidentally dropped; they're not a backup.
What it does

git stash saves your working directory changes and index to a stack, letting you switch contexts cleanly and restore later. Supports multiple stashes, partial stashing with -p, and stashing untracked files with -u.

Common flags
FlagMeaning
push -mStash with a descriptive message
popApply most recent stash and remove it
applyApply stash without removing it
listShow all stashes
dropDelete a specific stash
-uInclude untracked files
-pInteractively choose hunks to stash

Pro tip

Use `git stash push -u -m 'description'` to include untracked files — otherwise new files you've created stay in the working tree and may contaminate the branch you switch to.
