git

Distributed version control system for tracking and managing code changes.

medium riskForce push and history rewrite on shared branches can overwrite collaborators' work.
⚠ Risks & cautions
  • `git push --force` and other history rewrites can erase teammates’ commits; prefer --force-with-lease.
  • `git reset --hard` and `git clean -fd` delete uncommitted/untracked work that cannot be recovered.
  • Check `git status` and `git remote -v` before pushing so you do not push to the wrong remote or branch.
Safer / dry-run alternatives
git push --force-with-leaseForce push that refuses to overwrite commits you have not seen.
What it does

git tracks file changes through commits and supports branching and merging. The working directory, staging area (index), and repository are distinct zones. Remote operations interact with upstream repositories.

Pro tip

Use `git reflog` to recover lost commits after a bad reset or rebase — git keeps unreachable commits for ~90 days.
