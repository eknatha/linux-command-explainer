gpg

GNU Privacy Guard: encrypt, decrypt, sign, and verify files.

medium riskLosing private keys permanently locks encrypted data.
⚠ Risks & cautions
  • If you lose the private key (or its passphrase) the encrypted data is gone for good — back up keys and the revocation certificate.
  • `--export-secret-keys` output must stay offline and protected.
  • Verify fingerprints out-of-band before trusting a key.
What it does

gpg implements the OpenPGP standard for encryption, signing, and key management. Used for encrypting secrets, signing releases and commits, verifying software authenticity, and secure file transfer without shared passwords.

Pro tip

Always back up your private key: `gpg --export-secret-keys --armor user@email.com > private-key.asc`. Store it encrypted offline — key loss = permanent data loss.
