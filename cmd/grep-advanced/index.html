What it does

Beyond basic pattern matching, grep supports recursive directory search, context lines around matches, Perl-compatible regex (PCRE), and filtering by file type. Used heavily for log analysis, code search, and configuration auditing.

Common flags
FlagMeaning
-r/-RRecursive directory search
-l --files-with-matchesPrint only filenames, not matches
-c --countPrint match count per file
-A/-B/-CLines After/Before/Context of match
-P --perl-regexpPerl-compatible regex (PCRE)
--includeOnly search files matching pattern
-v --invert-matchPrint non-matching lines

Pro tip

Use `grep -rn 'pattern' . --include='*.py' --exclude-dir='.git'` for code search — the include/exclude flags prevent searching binaries and version control directories.
