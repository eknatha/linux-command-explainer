gzip

Compress or decompress files using the GNU zip DEFLATE algorithm.

low risk

What it does

gzip compresses a single file and replaces it with a .gz version. -k keeps the original. -d decompresses (same as gunzip). Compression level -1 (fastest) through -9 (best ratio). Combine with tar for multi-file archives.

Common flags
FlagMeaning
-d --decompressDecompress a .gz file (same as running gunzip)
-k --keepKeep the original file after compressing
-c --stdoutWrite output to stdout, don't replace file
-r --recursiveRecursively compress all files in a directory
-l --listShow compression ratio and sizes for .gz files
-1 --fastFastest compression, lowest ratio
-9 --bestBest compression ratio, slowest speed
-v --verboseShow compression ratio for each file processed

Pro tip

Use `zcat file.gz | grep pattern` to search inside a compressed file without decompressing it to disk first.
