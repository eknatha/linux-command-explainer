Get/set disk parameters

high riskSetting parameters or secure erase can brick or wipe a disk.
⚠ Risks & cautions
  • Never use write/security options on the wrong disk.
  • ATA secure erase destroys all data.
Safer / dry-run alternatives
hdparm -I <device>Identify before changing anything
What it does

Queries disk info and benchmarks; can change power, cache and security features.

Common flags
FlagMeaning
-IIdentify device
-tBenchmark reads
