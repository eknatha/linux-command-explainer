helm

Kubernetes package manager: install, upgrade, and manage chart releases.

⚠ Risks & cautions
  • Use `--dry-run --debug` or `helm diff upgrade` before upgrade/install.
  • `helm uninstall` deletes all release resources.
  • Pin chart versions (--version) so upgrades are reproducible.
What it does

Helm manages Kubernetes applications as charts — versioned packages of manifests with configurable values. It handles install, upgrade, rollback, and uninstall with release tracking. The --dry-run flag and diff plugin are essential for safe production operations.

Pro tip

Install the helm-diff plugin (`helm plugin install https://github.com/databus23/helm-diff`) and use `helm diff upgrade` before every upgrade — shows exactly what will change in the cluster.
