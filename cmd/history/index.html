history

Display or manipulate the shell command history.

⚠ Risks & cautions
  • History files can contain passwords and tokens typed on the command line; `history -c` hides your trail but may violate audit policy.
What it does

history lists previously executed commands with line numbers. You can re-run commands with !N (by number) or !! (last command). Ctrl+R provides interactive reverse search. HISTSIZE controls in-memory lines; HISTFILESIZE controls the history file.

Common flags
FlagMeaning
-c --clearClear all history (session)
-d --deleteDelete a specific history entry by number
-a --appendAppend session history to history file
-n --read-newRead new lines from history file

Pro tip

Prefix any command with a space to exclude it from history — useful for commands containing passwords or tokens (requires HISTCONTROL=ignorespace).
