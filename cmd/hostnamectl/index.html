hostnamectl

Query and set the system hostname, OS info, and machine identity.

low risk

low riskChanging hostname can affect network identity and break service configs that rely on it.
⚠ Risks & cautions
  • Changing the hostname can break software that stores it (monitoring, certificates, clustering, Kubernetes node names).
What it does

hostnamectl manages three hostname types: static (persistent, stored in /etc/hostname), transient (runtime, overridden by DHCP), and pretty (human-readable display name). Running without arguments shows OS, kernel, hardware, and virtualization info — useful for inventory scripting.

Common flags
FlagMeaning
set-hostnameSet the static system hostname persistently
--staticTarget the static hostname specifically
--transientTarget the transient (runtime) hostname
--prettyTarget the pretty (human-readable) hostname

Pro tip

After setting a new hostname, update /etc/hosts to map 127.0.1.1 to the new name — tools that do reverse DNS lookups will otherwise hang.
