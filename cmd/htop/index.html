htop

Interactive process viewer

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskRead-only view, but F9/k sends signals to processes.
⚠ Risks & cautions
  • Pressing F9/k then Enter sends a signal to the selected process — check the PID highlighted.
  • Run as a normal user for read-only viewing; only use root when you must signal other users’ processes.
What it does

Colourful top replacement with tree view, search and kill. F5 tree, F6 sort, F9 kill, F4 filter.

Common flags
FlagMeaning
-uShow one user
-pShow specific PIDs
-dRefresh delay (tenths of a second)
