install

Copy files and set mode/owner

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskOverwrites the destination and sets permissions/ownership in one step.
⚠ Risks & cautions
  • Overwrites an existing destination without asking.
  • Wrong -m/-o on files under /usr or /etc can open security holes or break services.
What it does

Copies files like cp but sets mode (-m), owner (-o) and group (-g) and can create parent directories (-D).

Common flags
FlagMeaning
-mSet permission mode
-oSet owner
-gSet group
-DCreate leading directories
-dCreate directories
Examples
