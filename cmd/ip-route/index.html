ip route

Manage and display the kernel routing table.

high riskIncorrect routes can break network connectivity.
⚠ Risks & cautions
  • Replacing or deleting the default route over SSH cuts you off.
  • Check with `ip route get <dest>` before and after.
  • Routes added with `ip route add` are not persistent.
Safer / dry-run alternatives
ip route show > /root/routes.backupSave the routing table.
ip route get <dest>See which route is used.
What it does

ip route manages the kernel IP routing table. Used for adding static routes, debugging routing decisions, and configuring policy-based routing. Changes are temporary (lost on reboot) unless written to network config files.

Examples

ip route add default via 192.168.1.1Set default gateway · explain & risk-check →
Pro tip

Use `ip route get <dest>` to instantly verify which gateway will be used for any destination — the most reliable way to debug routing issues without reading the full routing table.
