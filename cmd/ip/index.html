⚠ Risks & cautions
  • Taking down an interface or deleting the default route over SSH ends your session.
  • Changes are not persistent — they vanish on reboot (use NetworkManager/netplan/systemd-networkd to persist).
  • Verify first with `ip -br a` and `ip route get <ip>`.
Safer / dry-run alternatives
(sleep 120 && ip link set <if> up) &Safety net: re-enable the interface automatically.
ip route get <destination>See which route would be used before modifying routes.
What it does

ip is the modern replacement for ifconfig and route. It manages network interfaces, IP addresses, routes, ARP tables, and network namespaces. Changes made with ip are temporary (lost on reboot) unless written to network configuration files.

Pro tip

Use `ip route get <destination>` to instantly see which gateway and interface will be used to reach any IP — faster and more definitive than tracing routing tables manually.
