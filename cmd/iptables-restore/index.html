iptables-restore

Load iptables rules from a file

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskReplaces the active ruleset; a bad file can lock you out.
⚠ Risks & cautions
  • Always --test first; keep a second SSH session and an `at` rollback.
  • Without -n existing rules are flushed.
Safer / dry-run alternatives
iptables-restore --test < <file>Validate first
iptables-save > /root/iptables.beforeSave current rules
What it does

Atomically loads rules produced by iptables-save.

Common flags
FlagMeaning
-t --testParse only, do not commit
-nDo not flush existing rules
