iptables

Configure the Linux kernel firewall — manage network packet filtering rules.

high risk

high riskWrong rules can lock you out of SSH or drop critical traffic permanently.
⚠ Risks & cautions
  • Rules apply immediately; a wrong rule can drop your own SSH session.
  • Allow ESTABLISHED,RELATED and SSH BEFORE changing default policies.
  • Rules are not persistent — save them, and schedule a rollback before big changes.
Safer / dry-run alternatives
iptables-save > /root/iptables.backupBack up the current rules.
echo 'iptables-restore < /root/iptables.backup' | at now + 5 minutesAuto-rollback if you lock yourself out (cancel with atrm once verified).
What it does

iptables manages netfilter rules through chains. INPUT/OUTPUT/FORWARD handle incoming, outgoing, and routed traffic. Rules are evaluated top-to-bottom; first match wins. Save rules with iptables-save before making changes.

Common flags
FlagMeaning
-A --appendAppend a rule to a chain
-I --insertInsert a rule at the top (highest priority)
-D --deleteDelete a specific rule
-L --listList all rules in a chain
-n --numericShow numeric IPs without hostname resolution
-F --flushDelete all rules from a chain
Examples

Pro tip

Before adding restrictive rules on a remote server: `echo 'iptables -F' | at now + 5 minutes` — schedules a flush so you can't permanently lock yourself out.
