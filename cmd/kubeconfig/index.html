kubeconfig (advanced)

Manage Kubernetes contexts and clusters in kubeconfig.

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskSwitching context applies all commands to a different cluster.
⚠ Risks & cautions
  • The active context decides which cluster receives your next command — the classic way to hit production by mistake.
  • Kubeconfig files contain credentials: keep permissions 600 and never commit them.
  • `kubectl config use-context` is persistent; prefer --context per command for risky operations.
What it does

kubectl uses kubeconfig (~/.kube/config) to store cluster credentials and contexts. A context pairs a cluster with credentials and a namespace. Managing multiple clusters requires switching contexts — and verifying you're in the right one before destructive operations.

Pro tip

Install kubectx and kubens (`brew install kubectx`) for fast context/namespace switching. Set a PS1 prompt that shows current context — catching wrong-cluster mistakes before they happen.
