kubectl delete

Delete Kubernetes resources

high risk

high riskRemoves objects immediately; PVC/namespace deletion removes data.
⚠ Risks & cautions
  • Check context + namespace first: kubectl config current-context.
  • `delete ns` removes every resource inside — including PVCs and data.
  • --all and label selectors can match more than you expect — run `kubectl get` with the same selector first.
  • --force --grace-period=0 skips cleanup and can corrupt stateful workloads.
Safer / dry-run alternatives
kubectl get <kind> -l <selector> -n <ns>Preview what matches
kubectl delete <kind> <name> -n <ns> --dry-run=serverSimulate server-side
kubectl get <kind> <name> -n <ns> -o yaml > backup.yamlBack up the object
What it does

Deletes resources by name, label, file or --all.
