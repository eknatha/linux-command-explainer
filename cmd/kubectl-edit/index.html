⚠ Risks & cautions
  • Production edits drift from Git; GitOps tools may revert them.
  • A YAML mistake can roll out a broken pod template instantly.
Safer / dry-run alternatives
kubectl get deploy/<name> -o yaml > backup.yamlBack up first
kubectl diff -f <manifest>Change via a reviewed manifest instead

Opens the live object in $EDITOR. See the flags and examples below, and run `man kubectl` for the full reference.
