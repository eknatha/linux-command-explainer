kubectl exec

Execute commands inside a running Kubernetes container.

medium risk

medium riskDirect container access; avoid in production when possible.
⚠ Risks & cautions
  • Changes made inside the container vanish on restart and are not tracked.
  • In production prefer logs, metrics and `kubectl debug` with an ephemeral container.
  • Commands run with the container’s privileges — a root shell can modify mounted volumes.
What it does

kubectl exec runs commands inside a running container, similar to docker exec. The -- separator is required before the command. Use for live debugging — testing DNS resolution, checking env vars, verifying file contents — without redeploying.

Pro tip

Use `kubectl exec pod -- curl http://service.namespace.svc.cluster.local` to test service DNS and connectivity from within the cluster network — the most reliable way to verify network policies.
