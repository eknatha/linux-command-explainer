What it does

kubectl get is the primary read command for K8s. It lists resources with status. Output formats range from human-friendly tables to machine-parseable JSON/YAML. The -w flag watches for changes. Mastering -o and --field-selector transforms kubectl from a query tool into an automation backbone.

Common flags
FlagMeaning
-n --namespaceTarget namespace
-A --all-namespacesAll namespaces
-o --outputFormat: json, yaml, wide, jsonpath, custom-columns
-w --watchWatch for changes
--field-selectorFilter by field values
-l --selectorFilter by label

Pro tip

Use `kubectl get pods -o json | jq -r '.items[] | select(.status.phase!="Running") | .metadata.name'` to programmatically find non-running pods — far more reliable than parsing tabular output.
