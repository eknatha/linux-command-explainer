kubectl scale

high riskScaling to 0 stops the workload; scaling up consumes capacity.
⚠ Risks & cautions
  • --replicas=0 takes the service down.
  • GitOps controllers may revert manual scaling.
  • Scaling StatefulSets changes storage claims.
Safer / dry-run alternatives
kubectl get deploy/<name> -o jsonpath="{.spec.replicas}"Record the current value
kubectl scale deploy/<name> --replicas=<n> --current-replicas=<old>Use a precondition
What it does

Sets replicas of deployments/statefulsets.
