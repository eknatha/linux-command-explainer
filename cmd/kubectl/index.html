kubectl

Command-line tool for controlling Kubernetes clusters.

medium riskDeleting resources or applying bad configs can disrupt production workloads.
⚠ Risks & cautions
  • Confirm context and namespace first: kubectl config current-context.
  • `kubectl delete` has no undo — export objects and use --dry-run=server first.
  • Prefer declarative `apply -f` from Git over ad-hoc edit/patch, which causes drift.
What it does

kubectl communicates with the Kubernetes API server to manage cluster resources. Always verify your current context with `kubectl config current-context` before running destructive commands in production.

Common flags
FlagMeaning
