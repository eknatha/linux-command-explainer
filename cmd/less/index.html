⚠ Risks & cautions
  • Inside less, `!command` runs a shell command and `v` opens an editor — beware of piping sensitive files on shared screens.
What it does

less is an interactive file viewer that loads files page-by-page (unlike cat). Supports forward/backward navigation, regex search with /, and following live files with F. Handles arbitrarily large files efficiently.

Common flags
FlagMeaning
-N --line-numbersShow line numbers
-S --chop-long-linesDon't wrap long lines
-i --ignore-caseCase-insensitive search
-F --quit-if-one-screenExit if content fits on screen
Examples

less -N +/ERROR app.logOpen with line numbers, jump to first ERROR · explain & risk-check →
less +F /var/log/app.logStart in follow mode (like tail -f) · explain & risk-check →
Pro tip

Inside less, press `F` to enter follow mode (like tail -f), then `Ctrl+C` to stop following and browse backward — the best of both worlds.
