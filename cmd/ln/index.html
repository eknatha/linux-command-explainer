ln

Create hard or symbolic links between files.

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskDangling symlinks and circular links can cause confusion.
⚠ Risks & cautions
  • `ln -sf` replaces an existing link/file at the target without asking.
  • Relative symlinks are resolved from the link’s directory, not your current directory.
  • Hard links cannot cross filesystems or point to directories.
What it does

ln creates links — hard links share the same inode (same data, different name), while symbolic links (-s) are pointers to a path. Symlinks are the standard choice: they work across filesystems, can link directories, and make the relationship explicit.

Common flags
FlagMeaning
-s --symbolicCreate a symbolic link
-f --forceRemove existing destination before linking
-n --no-dereferenceTreat symlink destination as normal file
-v --verbosePrint link names

Pro tip

Use symlinks for version-managed deployments: keep versioned dirs (/opt/app/v1.2.3) and update a single symlink (/opt/app/current) for instant, reversible deploys.
