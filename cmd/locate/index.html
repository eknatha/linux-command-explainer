locate

Find files by name using an index

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskReads a prebuilt database; results may be stale or reveal paths you did not expect to see.
⚠ Risks & cautions
  • The index may list files that were deleted, or hide new ones, until updatedb runs.
What it does

Searches an index of filenames built by updatedb — much faster than find but only as fresh as the last index run.

Common flags
FlagMeaning
-iCase-insensitive match
-cCount matches only
-nLimit the number of results
-bMatch the basename only
