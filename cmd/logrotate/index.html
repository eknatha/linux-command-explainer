logrotate

Automatically rotate, compress, and manage log files.

What it does

logrotate manages log file rotation on a schedule — compressing old logs, deleting logs older than N days, and sending signals to services to reopen log files. Config in /etc/logrotate.conf and /etc/logrotate.d/. Run by cron or systemd timer daily.

Common flags
FlagMeaning
-d --debugDry run — show what would happen without doing it
-f --forceForce rotation even if not due
-v --verboseVerbose output

Pro tip

Always test new logrotate configs with `-d` (dry run) first. Common mistake: missing `postrotate` signal to the daemon to reopen files — without it, the service keeps writing to the rotated file.
