ls

List directory contents with optional detail and sorting.

What it does

ls reads directory entries and displays them. With -l it shows permissions, ownership, size, and timestamps. -a reveals hidden dotfiles. Pipe to grep or awk for filtering. Colors are controlled by LS_COLORS.

Common flags
FlagMeaning
-lLong format: permissions, links, owner, size, date
-a --allShow hidden files (starting with .)
-h --human-readablePrint sizes as K, M, G instead of bytes
-tSort by modification time, newest first
-R --recursiveList subdirectories recursively
-SSort by file size, largest first
Examples

Pro tip

Use `ls --color=always | less -R` to get colorized output inside less without losing terminal color codes.
