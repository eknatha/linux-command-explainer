lsblk

List block devices in a tree view showing partitions and mount points.

What it does

lsblk displays block devices (disks, partitions, LVM, NVMe) in a tree structure with sizes, types, and mount points. Far clearer than parsing fdisk or df output for understanding disk layout. The -f flag adds filesystem and UUID info.

Common flags
FlagMeaning
-f --fsShow filesystem type, UUID, and label
-d --nodepsDon't show device dependencies (list disks only)
-J --jsonJSON output
-o --outputSelect specific columns

Pro tip

Check `ROTA` column in `lsblk -d -o NAME,SIZE,ROTA` — ROTA=1 means HDD (spinning), ROTA=0 means SSD/NVMe. Critical for setting correct I/O scheduler and benchmark expectations.
