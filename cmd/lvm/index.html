lvm (advanced)

Logical Volume Manager: create, resize, and manage logical volumes.

high riskLVM operations on wrong volumes cause data loss.
⚠ Risks & cautions
  • Removing or reducing logical volumes destroys data — shrink the filesystem first and keep a snapshot or backup.
  • Save metadata with vgcfgbackup before big changes.
  • Check device names with lsblk — pvcreate/pvremove on the wrong disk wipes it.
Safer / dry-run alternatives
lvs -a -o +devices && vgs && pvsReview the layout first.
lvcreate -s -n pre_change -L 5G <vg>/<lv>Snapshot before resizing or modifying.
What it does

LVM abstracts physical storage into volume groups (VGs) and logical volumes (LVs) that can be resized live. The core workflow: create physical volumes (PVs) → group into VGs → carve out LVs. LVs can be snapshotted, resized online, and moved between physical disks.

Pro tip

Create LVM snapshots before risky operations: `lvcreate -s -L 2G -n pre_upgrade /dev/vg0/root` — if something goes wrong, revert instantly with `lvconvert --merge /dev/vg0/pre_upgrade`.
