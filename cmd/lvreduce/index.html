lvreduce

Shrink a logical volume

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskShrinking below the filesystem size destroys data.
⚠ Risks & cautions
  • Back up first; XFS cannot be shrunk.
  • Shrink the filesystem before the LV, never after.
Safer / dry-run alternatives
lvreduce -r -L <size> <lv>-r shrinks filesystem and LV in the right order
lvcreate -s -n pre_shrink -L 5G <vg>/<lv>Snapshot before shrinking
What it does

Reduces the size of an LV. The filesystem must be shrunk first.

Common flags
FlagMeaning
-rShrink the filesystem too
-LNew size
