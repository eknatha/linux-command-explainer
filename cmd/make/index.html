high riskRuns whatever the Makefile says, often as the invoking user.
⚠ Risks & cautions
  • Read the Makefile of untrusted projects before running `make` — it can execute any command.
  • `sudo make install` writes to system directories and has no uninstall; prefer packages or checkinstall.
  • Use -n to preview.
Safer / dry-run alternatives
make -n <target>Preview commands
What it does

Executes targets from a Makefile; `make install` copies files to system paths.
