modprobe

Load or remove kernel modules

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskLoading/unloading modules affects kernel stability and hardware.
⚠ Risks & cautions
  • Removing a module in use for network or storage drivers can drop connectivity or disks.
  • Out-of-tree modules can taint or crash the kernel — test first.
Safer / dry-run alternatives
modprobe -n -v <module>Dry run first
What it does

Adds or removes modules with dependencies resolved. Persistent configuration lives in /etc/modprobe.d/.

Common flags
FlagMeaning
-rRemove a module
-nDry run
-vVerbose
