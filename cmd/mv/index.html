mv

Move or rename files and directories.

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskOverwrites destination without warning and cannot be undone.
⚠ Risks & cautions
  • Overwrites the destination without asking (unless -i/-n).
  • Across filesystems mv is copy + delete — an interruption leaves partial data.
  • If the target directory does not exist, mv renames the source instead of moving it into a directory.
What it does

mv moves or renames files. Cross-filesystem moves copy then delete. Use -i for safety in scripts. Unlike cp, the original is always removed after a successful move.

Common flags
FlagMeaning
-i --interactivePrompt before overwriting
-n --no-clobberDo not overwrite existing files
-v --verboseShow what is being moved
-b --backupCreate a backup of each overwritten file
Examples
mv config.yml config.yml.bakRename file as backup before editing · explain & risk-check →
mv -v /tmp/deploy/* /var/www/html/Move all deploy files to web root verbosely · explain & risk-check →
mv -i *.log /archive/logs/Move all log files to archive with overwrite confirmation · explain & risk-check →
Pro tip

Use `mv -b` to auto-create tilde-suffixed backups (~) on overwrite — great for safe config file rotation.
