⚠ Risks & cautions
  • Use --safe-updates (or --i-am-a-dummy) on production.
  • Run `SELECT @@hostname, DATABASE();` to confirm the target.
  • Wrap changes in START TRANSACTION … COMMIT/ROLLBACK.
  • No password on the command line (visible in ps).
Safer / dry-run alternatives
mysql --safe-updates …Block unscoped updates/deletes
mysqldump --single-transaction <db> > backup.sqlBack up first
What it does

Client for MySQL/MariaDB. See the flags and examples below, and run `man mysql` for the full reference.
