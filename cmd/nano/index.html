medium riskEdits files directly; mistakes in system configs can break services.
⚠ Risks & cautions
  • Wrapped lines in config files like fstab or sshd_config can silently break them — use -w.
  • Validate config syntax before reloading services.
What it does

Beginner-friendly editor. Ctrl+O writes, Ctrl+X exits, Ctrl+W searches.

Common flags
FlagMeaning
-wDisable line wrapping (important for config files)
-BBackup existing file
-lShow line numbers
