nc advanced (advanced)

Netcat for port scanning, banner grabbing, and file transfer.

⚠ Risks & cautions
  • Exposing listeners or relaying traffic can bypass firewall policy.
  • Use only for diagnostics on hosts you control.
What it does

Beyond basic connectivity testing, netcat handles file transfers between hosts, banner grabbing to identify services, port range scanning, and UDP testing. It's often the only tool available on minimal installs for quick network diagnostics.

Pro tip

Use nc for lightweight file transfer when scp isn't available: `nc -l 9999 | tar xz` on receiver, `tar cz files/ | nc host 9999` on sender — no auth overhead, just raw speed.
