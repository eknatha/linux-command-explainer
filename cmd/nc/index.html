⚠ Risks & cautions
  • `nc -l` opens a port with no authentication or encryption.
  • -e / -c can provide remote shells — only in authorised tests.
  • Netcat variants (OpenBSD, ncat, traditional) have different flags.
What it does

nc (netcat) creates raw TCP/UDP connections for port testing, data transfer, and service simulation. Essential for testing if a port is open without a full client, checking firewall rules, or transferring files between systems.

Common flags
FlagMeaning
-v --verboseVerbose output
-z --zero-ioZero-I/O mode: scan without sending data
-w --timeoutConnection timeout in seconds
-l --listenListen mode: act as server
-u --udpUse UDP instead of TCP

Pro tip

Use `nc -zv host port 2>&1 | grep -i 'succeeded\|refused'` in health-check scripts — it tests TCP reachability without needing the actual application client.
