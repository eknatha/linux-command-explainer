ncdu

Interactive disk usage browser

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskScans disk (I/O heavy) but only deletes if you press d and confirm.
⚠ Risks & cautions
  • Pressing d deletes files — confirm carefully, especially as root.
  • Scanning large filesystems at peak time can slow production disks; use -x and run off-hours.
What it does

A curses disk-usage analyzer. Navigate with arrows, press d to delete the selected item.

Common flags
FlagMeaning
-xStay on one filesystem
--exclude --excludeSkip paths
-oExport scan to a file
