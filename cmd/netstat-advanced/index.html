What it does

netstat shows network connections, routing tables, interface statistics, and more. While ss is faster and more modern, netstat is more widely installed and familiar. -tlnp is the canonical one-liner for 'what's listening on what port' on servers without ss.

Common flags
FlagMeaning
-tTCP connections
-uUDP connections
-lListening sockets only
-nNumeric (don't resolve hostnames)
-pShow PID/program name
-rDisplay routing table
-iNetwork interface statistics

Pro tip

Prefer `ss -tlnp` on modern systems — netstat reads from /proc and can be slow on systems with many connections, while ss uses kernel netlink sockets and is orders of magnitude faster.
