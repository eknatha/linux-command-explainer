⚠ Risks & cautions
  • `nft flush ruleset` wipes every rule, including NAT used by containers/Kubernetes.
  • Load rules atomically from a file and test with `nft -c -f file`.
  • Keep a backup: nft list ruleset > /root/nft.backup.

What it does

nftables is the successor to iptables/ip6tables, using a unified syntax for IPv4, IPv6, ARP, and bridge filtering. It's the default on Debian 10+, RHEL 8+. Rules are organized into tables → chains → rules. The nft command manages everything.

Pro tip

Use `nft list ruleset > /etc/nftables.conf` to export and save current rules — then `nft -f /etc/nftables.conf` on boot to restore them. Much cleaner than iptables-save.
