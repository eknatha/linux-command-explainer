nohup

Run a command immune to hangup signals (SSH disconnects).

⚠ Risks & cautions
  • Output goes to nohup.out in the current directory (can grow without limit) — redirect it explicitly.
What it does

nohup runs a command that won't be killed when the terminal session ends (SIGHUP is ignored). Output goes to nohup.out by default. A quick alternative to tmux/screen for one-off long-running commands.

Pro tip

Always redirect both stdout and stderr with `> out.log 2>&1` when using nohup — otherwise output goes to nohup.out in whatever directory you ran it from.
