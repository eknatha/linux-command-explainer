⚠ Risks & cautions
  • Binding memory to one NUMA node can cause out-of-memory errors even when other nodes have free memory.
  • Test policy changes on staging; wrong CPU/memory binding degrades latency-sensitive services.

Run processes with NUMA policies. See the flags and examples below, and run `man numactl` for the full reference.
