openssl

Cryptography toolkit — TLS testing, key/certificate generation, and data encoding.

medium riskWeak key sizes or mishandled private keys create serious security vulnerabilities.
⚠ Risks & cautions
  • Never share private keys; protect them with chmod 600 and a passphrase.
  • Use RSA ≥ 3072 or ECDSA/Ed25519 and SHA-256+; avoid SHA-1/MD5.
  • -nodes / -noenc writes the private key unencrypted.
What it does

openssl is a comprehensive crypto toolkit. It generates RSA/EC keys, creates CSRs, signs certificates, tests TLS handshakes, encodes/decodes base64, and computes hashes. Essential for PKI management, HTTPS setup, and debugging TLS certificate issues.

Examples

Pro tip

Check remote cert expiry without downloading a file: `echo | openssl s_client -connect host:443 2>/dev/null | openssl x509 -noout -dates`
