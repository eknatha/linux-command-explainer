parallel

Execute jobs in parallel from command line or files.

medium riskParallel execution can overload systems or APIs if not rate-limited.
⚠ Risks & cautions
  • Many parallel jobs can overload the machine or hit API rate limits — set -j explicitly.
  • File names with spaces/metacharacters need quoting (-q) — otherwise the wrong files are processed.
  • Test with --dry-run first.
What it does

GNU parallel runs jobs concurrently across CPU cores or remote hosts, replacing xargs -P with a more powerful and flexible interface. Supports progress bars, retry logic, input from files, and running across SSH hosts. Essential for bulk operations.

Common flags
FlagMeaning
-j --jobsNumber of parallel jobs (default: CPU count)
--delayDelay between job starts
--retriesRetry failed jobs N times
--progressShow progress bar
-S --sshRun jobs on remote hosts via SSH
Examples

Pro tip

Use `parallel --delay 0.1` when hitting APIs to avoid rate limiting — adds 100ms between job starts while still running many jobs concurrently.
