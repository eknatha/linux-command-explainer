Partition editor

high risk

interactive breakdown — edit the command and press Explain

high riskApplies changes immediately; wrong device or range destroys data.
⚠ Risks & cautions
  • mklabel wipes the partition table — all data becomes inaccessible.
  • -s skips confirmations.
  • Verify the device with lsblk -o NAME,SIZE,MODEL,SERIAL.
Safer / dry-run alternatives
parted /dev/sdX printInspect before changing
sfdisk -d /dev/sdX > sdX.ptBack up the table
What it does

Create, resize and delete partitions, supports GPT and large disks. Many commands act at once in script mode.

Common flags
FlagMeaning
printShow the partition table
mklabelCreate a new partition table (destroys existing)
mkpartCreate a partition
rmDelete a partition
-sScript mode: no prompts
