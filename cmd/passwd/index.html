passwd

Change or set a user account password.

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskLocking or changing passwords affects user access.
⚠ Risks & cautions
  • `passwd -l` on the only admin or root account can lock everybody out.
  • `passwd -d` removes the password (an empty password).
  • Prefer SSH keys and enforce policy with chage.
What it does

passwd updates /etc/shadow. Root can change any user's password. -l locks an account, -u unlocks, -e forces a password change on next login.

Common flags
FlagMeaning
-l --lockLock the account (prefix ! in shadow)
-u --unlockUnlock a locked account
-e --expireForce password change on next login
