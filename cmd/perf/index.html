⚠ Risks & cautions
  • Sampling at high frequency adds overhead on production hosts; keep runs short.
  • Recorded data can include process names, arguments and memory addresses — treat perf.data as sensitive.
What it does

perf is the Linux performance profiling tool, using hardware counters and kernel tracepoints. It records CPU samples, tracks cache misses, counts system calls, and generates flame graphs. Essential for diagnosing performance bottlenecks at the CPU/kernel level.

Common flags

Pro tip

Combine `perf record -g` with FlameGraph scripts (`perf script | stackcollapse-perf.pl | flamegraph.pl > flame.svg`) to generate visual CPU flame graphs — the most powerful way to find hot code paths.
