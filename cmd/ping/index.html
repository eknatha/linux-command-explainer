⚠ Risks & cautions
  • `ping -f` (flood) needs root and can overload targets or links; only use on your own networks.
What it does

ping sends ICMP echo requests to test if a host is reachable and measure round-trip time. On Linux, ping runs indefinitely by default (unlike macOS) — use -c to limit packets. The -i flag controls interval, -s sets packet size for bandwidth testing.

Common flags
FlagMeaning
-c --countNumber of packets to send
-i --intervalSeconds between packets
-t --ttlSet Time To Live
-s --sizePacket size in bytes
-W --timeoutSeconds to wait for reply

Pro tip

Use `ping -c 100 -q host` for a quick latency baseline — the -q flag shows only statistics. Compare min/avg/max/mdev to identify jitter vs consistent latency issues.
