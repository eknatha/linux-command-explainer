podman

Daemonless container runtime compatible with Docker CLI.

medium riskRootless by default; some Docker behaviors differ.
⚠ Risks & cautions
  • Rootless mode limits privileges, but --privileged or mounting host paths still gives broad access.
  • Docker-compatible flags can behave differently (networking, volume ownership, systemd integration) — test before production use.
What it does

Podman is a daemonless container engine that's fully OCI-compatible and largely drop-in compatible with Docker commands. It runs rootless by default (more secure), supports pods natively (like Kubernetes pods), and generates Kubernetes YAML from running containers.

Pro tip

Use `podman generate kube container_name` to convert a working local container to Kubernetes YAML — faster than writing manifests from scratch when prototyping.
