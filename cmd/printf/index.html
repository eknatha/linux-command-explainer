What it does

printf formats output using format specifiers (like C printf). More predictable than echo — doesn't add a newline by default, handles escape sequences consistently, and supports format strings for aligned output in scripts.

Examples
printf 'Name: %s\nAge: %d\n' 'Alice' 30Formatted multi-line output · explain & risk-check →
printf '%10s %5s\n' 'Host' 'Status'Right-aligned column headers · explain & risk-check →

printf '%b' '\033[32mGreen Text\033[0m\n'Print colored text in scripts · explain & risk-check →
Pro tip

Use printf instead of echo in scripts for portability — echo behavior with -e and escape sequences varies across shells and implementations.
