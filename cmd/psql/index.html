high riskDirect database access; queries can modify or drop data.
⚠ Risks & cautions
  • Autocommit is on: an UPDATE/DELETE without WHERE is applied immediately. Wrap manual changes in BEGIN; … COMMIT/ROLLBACK.
  • Check where you are connected first: select current_database(), inet_server_addr();
  • Do not pass passwords on the command line — use ~/.pgpass or PGPASSFILE.
Safer / dry-run alternatives
psql -v ON_ERROR_STOP=1 -1 -f change.sql <db>Run a script in ONE transaction (-1) that stops at the first error.
pg_dump -Fc <db> > before.dumpTake a backup before schema or bulk data changes.
What it does

psql is the interactive terminal for PostgreSQL. Beyond running queries, it supports meta-commands (\d, \l, \c) for schema inspection, bulk loading with \copy, and scripting with -c and -f flags. Essential for database administration and debugging.

Common flags
FlagMeaning
-h --hostDatabase host
-U --usernameDatabase user
-d --dbnameDatabase name
-c --commandRun a single SQL command
-f --fileExecute SQL from file
-t --tuples-onlyPrint only data rows (no headers)
Examples

Pro tip

Use `psql -U postgres -c 'SELECT pg_size_pretty(pg_database_size(datname)), datname FROM pg_database ORDER BY 1 DESC;'` to instantly identify bloated databases on shared hosts.
