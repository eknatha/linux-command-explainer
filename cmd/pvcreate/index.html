pvcreate

Initialize a physical volume for LVM

high risk

high riskWrites LVM metadata to the device, destroying existing data.
⚠ Risks & cautions
  • Destroys the existing signature on the device.
  • Check lsblk -f first; never run on a disk with data you need.
Safer / dry-run alternatives
pvs && lsblk -fInspect existing layout first
What it does

Marks a block device as an LVM PV. See the flags and examples below, and run `man pvcreate` for the full reference.
