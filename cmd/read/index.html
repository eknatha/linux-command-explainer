read

Read input from stdin or user prompt into shell variables.

⚠ Risks & cautions
  • Without -r, backslashes in input are interpreted; use `read -rs` for secrets so they are not echoed.
What it does

read captures user input or reads lines from stdin into shell variables. Used for interactive scripts, parsing file content line-by-line, and prompting for secrets (with -s to disable echo). The -r flag prevents backslash interpretation.

Common flags
FlagMeaning
-r --rawRaw mode: don't interpret backslashes
-s --silentSilent mode: don't echo input (for passwords)
-p --promptPrint prompt before reading
-t --timeoutTimeout in seconds
-a --arrayRead words into an array

Pro tip

Always use `IFS= read -r line` when reading file lines — prevents leading/trailing whitespace stripping and backslash interpretation that causes subtle bugs.
