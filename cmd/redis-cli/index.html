⚠ Risks & cautions
  • FLUSHALL/FLUSHDB delete data instantly and replicate to replicas.
  • KEYS * blocks the server on large datasets — use `--scan` (SCAN) instead.
  • Confirm which instance you are connected to (-h/-p, INFO server) before any write command.
What it does

redis-cli is the interactive and scripted client for Redis. Used for inspecting cache contents, monitoring live commands, checking memory usage, and diagnosing performance issues. The MONITOR command streams all Redis commands in real time.

Pro tip

Use `redis-cli --bigkeys` to find oversized keys before they cause memory pressure. Use `--scan` instead of `KEYS *` in production — KEYS * blocks Redis for the entire scan duration.
