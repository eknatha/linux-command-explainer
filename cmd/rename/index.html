rename

Rename multiple files with a pattern

high risk

$ 
high riskBatch renames can overwrite or scramble many files at once.
⚠ Risks & cautions
  • Always run with -n first (Perl rename).
  • Two source files mapping to the same name overwrite each other with -f.
  • The Perl and util-linux versions have different syntax — check `rename --version`.
Safer / dry-run alternatives
rename -n 's/old/new/' *.txtDry run first
What it does

Renames files using a Perl regex (Debian/Ubuntu) or a simple string substitution (util-linux). Syntax differs between implementations.

Common flags
FlagMeaning
-nDry run: show what would be renamed (Perl rename)
-vVerbose
-fForce overwriting existing files
