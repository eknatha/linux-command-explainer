resize2fs

Resize ext filesystems

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskShrinking a filesystem without a backup can corrupt data.
⚠ Risks & cautions
  • Shrink the filesystem BEFORE shrinking the LV/partition, never after.
  • Back up first and run e2fsck -f.
Safer / dry-run alternatives
e2fsck -f <device>Check before resizing
lvextend -r -L +10G <lv>Extend LV + filesystem in one step
What it does

Grows or shrinks ext2/3/4. Growing can be done online; shrinking needs unmount and fsck.

Examples
