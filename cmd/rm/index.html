rm

Remove files or directories permanently with no recycle bin.

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskPermanently deletes files. No undo. No trash. Irreversible.
⚠ Risks & cautions
  • No trash, no undo — deleted files are gone.
  • Preview with `ls` or `echo rm …` first, especially with globs and variables.
  • Never run `rm -rf` with a variable that might be empty or unquoted.
  • rm does not ask before deleting files you can write; use -i or -I to be prompted.
Safer / dry-run alternatives
ls -la <target>Preview what you are about to delete.
rm -rI <dir>Ask once before a recursive delete (-I); use -i to be asked for every file.
trash-put <path>Move to the trash (trash-cli) so it can be recovered.
What it does

rm deletes files immediately. There is no recycle bin on Linux. The -rf combination recursively forces deletion — extremely dangerous near / or $HOME. Always double-check paths in scripts and never use unquoted variables.

Common flags
FlagMeaning
-r --recursiveRemove directories and all their contents
-f --forceIgnore nonexistent files, never prompt
-i --interactivePrompt before every removal
-v --verboseShow each file as it is removed

Pro tip

Never run `rm -rf $VAR/path` — if $VAR is empty it becomes `rm -rf /path`. Always validate and quote variables before destructive commands.
