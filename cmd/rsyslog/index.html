⚠ Risks & cautions
  • A syntax error in rsyslog.conf can stop logging entirely — validate with `rsyslogd -N1`.
  • Forwarding logs over UDP can lose messages; use TCP/RELP with disk-assisted queues.
  • Rotate and cap local log files so /var does not fill up.
What it does

rsyslog is the high-performance system logging daemon used on most Linux distros alongside or instead of systemd's journald. It processes logs using rules (facility.severity → destination) and can forward logs to remote servers. Config files live in /etc/rsyslog.conf and /etc/rsyslog.d/.

Pro tip

Use `rsyslogd -N1` to validate config before restarting — a syntax error in rsyslog.conf silently stops all logging, which you'll only notice during an incident.
