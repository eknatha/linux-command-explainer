sar

Collect and report system activity statistics over time.

What it does

sar (System Activity Reporter) collects and reports CPU, memory, network, and disk statistics. Unlike vmstat/iostat which show current state, sar records historical data (when sadc daemon runs) enabling you to analyze what happened during an incident hours ago.

Common flags
FlagMeaning
-u --cpuCPU utilization
-r --memoryMemory statistics
-n DEVNetwork interface statistics
-b --ioI/O statistics
-f --fileRead from a saved data file
Examples

Pro tip

Enable sysstat's cron job (`/etc/cron.d/sysstat`) so sar continuously records history. After an incident, use `sar -u -f /var/log/sysstat/saNN` to replay what CPU/memory did during the event.
