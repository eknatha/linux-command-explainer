screen

Terminal multiplexer with persistent sessions (older alternative to tmux).

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskSessions persist after logout; orphaned sessions consume resources.
⚠ Risks & cautions
  • Detached sessions keep running and keep their scrollback — close them and avoid leaving root shells open.
What it does

screen provides persistent terminal sessions that survive SSH disconnects, similar to tmux. While tmux is more modern and feature-rich, screen is often the only multiplexer available on minimal server installs.

Examples
screen -S mysessionCreate named session · explain & risk-check →
screen -r mysessionReattach to session · explain & risk-check →
screen -lsList all sessions · explain & risk-check →
screen -X -S mysession quitKill a session from outside · explain & risk-check →
Pro tip

Inside screen: Ctrl+a d (detach), Ctrl+a c (new window), Ctrl+a " (list windows). Prefer tmux for new setups — screen is for when you're on a system without tmux.
