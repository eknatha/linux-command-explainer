Advanced sed: multi-line editing, in-place replacement, complex patterns.

⚠ Risks & cautions
  • -i modifies files in place — use -i.bak.
  • Complex multi-line scripts are hard to review; keep them in a file (-f script.sed).
  • Test on a copy of the file first.
What it does

Beyond simple substitution, sed supports in-place file editing, multi-line patterns, address ranges, and script files. The -i flag is essential for automated config management — patching configuration files without opening an editor.

Common flags
FlagMeaning
-iEdit file in-place (-i.bak to backup)
-nSuppress automatic print (use with p)
-eAdd script expression
-r/-EExtended regular expressions
Examples

Pro tip

Always use `-i.bak` in scripts for in-place edits — creates a backup automatically. Remove backup files with `find . -name '*.bak' -delete` after confirming changes.
