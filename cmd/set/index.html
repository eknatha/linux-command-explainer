set

Set shell options and positional parameters; control script safety.

medium risk

medium riskDisabling safety options (e.g., set +e) can mask script failures.
⚠ Risks & cautions
  • `set +e` hides failures; `set -x` can print secrets into logs.
  • Use `set -euo pipefail` at the top of scripts and understand its edge cases (||, if, subshells).
  • `set -- args` replaces the positional parameters.
What it does

set configures shell options that dramatically affect script behavior. `set -e` makes scripts exit on any error. `set -u` treats unset variables as errors. `set -o pipefail` catches failures in pipelines. Together, they make scripts fail-fast and safe.

Pro tip

Start every bash script with `#!/bin/bash\nset -euo pipefail` — `e` exits on error, `u` catches unset variables, `pipefail` catches pipeline failures. This prevents 90% of silent script bugs.
