setcap

Set file capabilities

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskGrants privileged powers to a binary; misuse creates privilege-escalation paths.
⚠ Risks & cautions
  • Capabilities like cap_sys_admin or cap_setuid are effectively root.
  • They are lost when the file is replaced by an upgrade.
Safer / dry-run alternatives
systemctl edit <unit> # AmbientCapabilities=CAP_NET_BIND_SERVICEGrant capabilities via systemd instead
What it does

Assigns capabilities such as cap_net_bind_service to executables.

Common flags
FlagMeaning
-rRemove capabilities
Examples
