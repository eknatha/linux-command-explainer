setenforce

Switch SELinux between enforcing and permissive

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskPermissive mode disables enforcement until reboot, weakening protection.
⚠ Risks & cautions
  • setenforce 0 is a diagnostic, not a fix — find the denial with ausearch and write policy instead.
  • Don’t forget to return to enforcing.
Safer / dry-run alternatives
ausearch -m avc -ts recent | audit2whyDiagnose the denial
semanage fcontext -a -t <type> "<path>(/.*)?" && restorecon -Rv <path>Fix the label
What it does

Changes the runtime SELinux mode; does not survive reboot.
