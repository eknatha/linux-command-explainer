setfacl

Set file access control lists

high risk

high riskChanges who can read/write files; recursive mistakes expose data or lock users out.
⚠ Risks & cautions
  • Back up first: getfacl -R path > acl.bak (restore with setfacl --restore=acl.bak).
  • -b -R removes every ACL under the tree.
  • ACLs are easy to forget — review with getfacl during audits.
Safer / dry-run alternatives
getfacl -R <path> > acl.bakBack up current ACLs
setfacl --restore=acl.bakRestore them if needed
What it does

Adds, modifies or removes ACL entries. Use for fine-grained sharing without changing groups.

Common flags
FlagMeaning
-mModify ACL entries
-xRemove entries
-bRemove all ACLs
-RRecurse
-dSet default ACL for new files
Examples
