medium riskRuns arbitrary commands; behaviour differs from bash.
⚠ Risks & cautions
  • `curl … | sh` runs unseen remote code.
  • Test scripts with the same shell they will use in production (shebang matters).
What it does

On Debian/Ubuntu sh is dash; on RHEL it is bash in POSIX mode. Bash-only syntax ([[ ]], arrays) fails.
