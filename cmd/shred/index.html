shred

Overwrite a file to make recovery harder

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskDestroys data irrecoverably; ineffective on journaling, SSD and copy-on-write filesystems.
⚠ Risks & cautions
  • Irreversible — there is no undo and no trash.
  • Does NOT reliably wipe data on SSDs, RAID, snapshots, btrfs/ZFS or journaled data — use full-disk encryption and secure erase.
  • Double-check the filename; a wrong target is lost for good.
Safer / dry-run alternatives
ls -l <file>Confirm the target first
cryptsetup luksErase <device>For disks: use encryption + crypto-erase
What it does

Overwrites a file multiple times, optionally deleting it (-u).

Common flags
FlagMeaning
-uRemove the file afterwards
-nNumber of overwrite passes
-zAdd a final pass of zeros
-vShow progress
