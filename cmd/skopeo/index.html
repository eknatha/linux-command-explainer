skopeo

Inspect, copy, and sync container images without a runtime.

What it does

skopeo operates on container images in registries without needing a container runtime or root. It inspects images (tags, layers, config), copies images between registries, and syncs registry contents. Essential for registry migrations and air-gapped environments.

Examples

Pro tip

Use `skopeo list-tags` in CI to check if a specific image tag exists before pulling — prevents misleading 'image not found' errors mid-pipeline.
