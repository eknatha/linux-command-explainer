⚠ Risks & cautions
  • `sleep` in scripts is a race-condition workaround — poll for the condition you actually need.
What it does

sleep pauses the shell for a given number of seconds (or minutes/hours with m/h suffixes on GNU sleep). Used in retry loops, rate limiting, and waiting for services to start. Often overused where proper readiness checks are better.

Pro tip

Replace `sleep 30` in startup scripts with a readiness loop: `until curl -sf http://localhost:8080/health; do sleep 2; done` — adapts to actual readiness instead of guessing.
