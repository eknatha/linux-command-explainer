⚠ Risks & cautions
  • Listeners bind to all interfaces by default — add bind=127.0.0.1.
  • EXEC: addresses can run commands for any connecting client.
  • Relays can bypass firewall policy.
Safer / dry-run alternatives
socat TCP-LISTEN:8080,bind=127.0.0.1,fork TCP:backend:80Bind to localhost only
What it does

Connects two data streams: sockets, files, pipes and TLS endpoints.
