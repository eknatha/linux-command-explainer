source

Execute a script in the current shell context (no subshell).

⚠ Risks & cautions
  • Sourcing runs every command in the file in your current shell — only source files you trust and have read.
What it does

source (or its synonym `.`) runs a script in the current shell rather than a subshell — so variables, functions, and aliases defined in the script persist after it finishes. Essential for applying changes to ~/.bashrc without restarting the terminal.

Pro tip

Use `source .env` in dev workflows — keep secrets in .env (gitignored) and load them on demand rather than exporting globally.
