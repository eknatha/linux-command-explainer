Split a file into pieces

low riskCreates many new files in the current directory.
⚠ Risks & cautions
  • Output files go to the current directory — run it in an empty one.
  • Reassemble with `cat part_* > file` and verify with a checksum.
What it does

Splits a file by size or line count into numbered chunks.

Common flags
FlagMeaning
-lLines per output file
-bBytes per output file (e.g. 100M)
-dUse numeric suffixes
--additional-suffix --additional-suffixAppend a suffix to chunk names
Examples
split -b 100M -d big.iso part_Split into 100 MB parts · explain & risk-check →
