What it does

ss (socket statistics) is the modern replacement for netstat. Beyond basic port listing, it supports powerful filters by TCP state, destination, source, and process. The state filter lets you count and analyze connections in specific TCP states — critical for diagnosing connection exhaustion.

Common flags
FlagMeaning
-t --tcpTCP sockets only
-u --udpUDP sockets only
-l --listeningListening sockets only
-p --processesShow process using the socket
-n --numericDon't resolve hostnames
-s --summarySummary statistics

Pro tip

Use `ss -s` for an instant health snapshot — if TIME_WAIT count is very high (thousands), your app isn't reusing connections. Enable TCP keep-alive or connection pooling.
