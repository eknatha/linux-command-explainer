ssh-add

Add keys to the SSH agent

low risk

low riskKeeps decrypted keys in memory.
⚠ Risks & cautions
  • Forwarding the agent (-A) lets remote root use your keys — prefer ProxyJump.
  • Use -t to limit key lifetime.
What it does

Loads private keys into ssh-agent. See the flags and examples below, and run `man ssh-add` for the full reference.

Common flags
FlagMeaning
-lList loaded keys
-DDelete all keys
-tLifetime in seconds
Examples
