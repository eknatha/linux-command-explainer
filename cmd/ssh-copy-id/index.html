medium riskModifies authorized_keys on the remote host.
⚠ Risks & cautions
  • Verify the host fingerprint before first login.
  • Remove old keys when people leave; review authorized_keys regularly.
What it does

Appends your public key to ~/.ssh/authorized_keys remotely.
