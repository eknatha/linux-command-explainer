ssh-keygen

Generate, inspect, and manage SSH public/private key pairs.

low riskPrivate keys must be protected — exposure grants unauthorized SSH access.
⚠ Risks & cautions
  • Do not overwrite an existing key — check the target path first.
  • Protect private keys with a passphrase and chmod 600; `ssh-keygen -R` only edits known_hosts.
What it does

ssh-keygen creates key pairs for passwordless SSH authentication. Ed25519 is the modern standard — shorter, faster, and more secure than RSA. -C adds an identifying comment. -f sets the filename. -R removes stale entries from known_hosts.

Common flags
FlagMeaning
-tKey type: ed25519 (recommended), ecdsa, rsa
-bKey bits — for RSA: minimum 2048, prefer 4096
-CComment to identify the key (typically email or hostname)
-fOutput filename for the key pair
-NPassphrase for the private key ('' for none)
-pChange the passphrase of an existing private key
-lShow fingerprint of a public key file
-RRemove a host entry from ~/.ssh/known_hosts
Examples

Pro tip

Always prefer Ed25519: `ssh-keygen -t ed25519` — the public key is 68 characters vs 800+ for RSA-4096, with stronger security properties.
