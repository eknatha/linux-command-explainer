high riskMistakes in sshd_config can lock you out.
⚠ Risks & cautions
  • Always run sshd -t before reload; keep a second session open.
  • PermitRootLogin yes and PasswordAuthentication yes increase attack surface.
Safer / dry-run alternatives
sshd -t && systemctl reload sshdValidate, then reload (not restart)
What it does

Daemon accepting SSH connections; -t validates configuration.
