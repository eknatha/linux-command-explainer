stat

Display detailed metadata about files and filesystems.

What it does

stat shows comprehensive file metadata: inode number, permissions in both octal and symbolic form, link count, ownership, file size, and all three timestamps (access, modify, change). Far more informative than ls -l for debugging permission and timing issues.

Common flags
FlagMeaning
-c --formatUse a custom output format
-f --file-systemShow filesystem status instead
-L --dereferenceFollow symlinks

Pro tip

Use `stat -c '%a'` in scripts to check exact octal permissions — more reliable than parsing `ls -l` output which varies by implementation.
