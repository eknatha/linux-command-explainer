strace

Trace system calls and signals made by a process.

⚠ Risks & cautions
  • Attaching to a live process can slow it 2–50× and cause timeouts in production — time-box it and use -c for summaries.
  • Output may contain secrets (read/write buffers, environment).
What it does

strace intercepts and logs every system call (open, read, write, socket, etc.) made by a process. The go-to tool for debugging 'permission denied' errors, missing files, and mysterious failures — shows exactly what the kernel sees.

Common flags
FlagMeaning
-p --attachAttach to an already-running process by PID
-e --exprFilter to specific system calls
-f --follow-forksFollow child processes
-o --outputWrite output to file instead of stderr
-c --summaryPrint summary statistics only
-t --timestampPrefix each line with timestamp

Pro tip

Use `strace -e trace=openat,read,write` to narrow output — full strace output is overwhelming; filtering to file I/O syscalls finds 80% of 'permission denied' bugs fast.
