sudo

Run commands as another user (usually root)

high riskRuns with elevated privileges; one typo can damage the whole system.
⚠ Risks & cautions
  • Re-read the whole command before pressing Enter — especially paths and globs.
  • Avoid `sudo -i`/`sudo su` for routine work; they hide actions from the audit trail.
  • Never edit /etc/sudoers directly — use visudo.
  • Redirections run as YOU, not root: `sudo echo x > /etc/f` fails; use `| sudo tee`.
Safer / dry-run alternatives
sudo -lCheck what you may run
sudoedit <file>Edit root files safely
sudo -kDrop cached credentials when finished
What it does

Executes a command as root or another user according to /etc/sudoers.
