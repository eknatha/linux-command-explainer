systemctl restart

Restart a service

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskDrops connections and briefly interrupts the service.
⚠ Risks & cautions
  • Validate the configuration first (nginx -t, sshd -t, apachectl configtest).
  • Restart of databases and message brokers can take minutes and trigger failovers.
Safer / dry-run alternatives
systemctl reload <unit>Prefer reload if supported
systemctl status <unit> --no-pagerVerify afterwards
What it does

Stops then starts a unit; use reload for configuration changes where supported.
