What it does

Systemd timers replace cron for scheduled tasks, offering dependency management, precise logging via journald, and missed-run catch-up (Persistent=true). A timer unit (.timer) pairs with a service unit (.service) that defines what to run.

Pro tip

Use `systemd-analyze calendar 'your-expression'` to validate timer calendar expressions before deploying — shows next 10 trigger times, saving debugging time.
