tail

Output the last N lines of a file; follow live output.

What it does

tail outputs the last N lines (default 10). The -f flag follows a file as it grows — the standard way to monitor live logs. -F is more robust than -f as it handles log rotation.

Common flags
FlagMeaning
-n --linesOutput the last N lines
-f --followFollow file growth in real time
-F --follow-nameFollow by filename (survives log rotation)
-c --bytesOutput the last N bytes
Examples

Pro tip

Use `tail -F` instead of `tail -f` in production log monitoring — it reconnects when the file is rotated, preventing silent monitoring gaps.
