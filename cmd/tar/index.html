tar

Archive and compress files — the standard Linux backup and packaging tool.

medium riskExtraction can overwrite existing files; archives may contain absolute paths.
⚠ Risks & cautions
  • Extraction overwrites existing files silently — list first with `tar -tf`.
  • Archives can contain absolute paths or ../ entries; inspect before extracting as root.
  • Use -C <dir> to control where files are extracted.
What it does

tar bundles files into an archive. Combined with gzip (-z), bzip2 (-j), or xz (-J) it compresses too. The -C flag changes extraction directory. Always inspect archives with -t before extracting to avoid surprises.

Common flags
FlagMeaning
-c --createCreate a new archive
-x --extractExtract files from an archive
-t --listList archive contents without extracting
-z --gzipCompress/decompress with gzip (.tar.gz)
-j --bzip2Compress/decompress with bzip2 (.tar.bz2)
-J --xzCompress/decompress with xz (.tar.xz) — best compression ratio
-f --fileSpecify archive filename
-v --verboseVerbosely list files processed
-C --directoryChange to directory before extracting
Examples

Pro tip

Exclude directories on archive: `tar --exclude='./logs' --exclude='./.git' -czf archive.tar.gz .`
