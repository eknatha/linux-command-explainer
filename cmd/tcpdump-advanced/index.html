What it does

tcpdump captures network packets and displays or saves them for analysis. Beyond basic capture, it supports BPF filter expressions to target specific hosts, ports, or protocols. Captured files in pcap format can be analyzed in Wireshark.

Common flags
FlagMeaning
-iInterface to capture on
-wWrite to pcap file
-rRead from pcap file
-nDon't resolve hostnames
-v/-vv/-vvvVerbosity levels
-cCapture N packets then stop
-sSnap length (0 = full packet)
Examples

tcpdump -r capture.pcap -n | grep HTTPAnalyze saved pcap for HTTP · explain & risk-check →
tcpdump -i eth0 'tcp[tcpflags] & tcp-syn != 0'Capture only SYN packets (detect port scans) · explain & risk-check →
Pro tip

Use `tcpdump -i any -w - | ssh user@analyst-host 'wireshark -k -i -'` to stream live capture directly to a remote Wireshark — analyze production traffic without storing pcap files locally.
