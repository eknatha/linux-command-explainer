tcpdump

Capture and analyze raw network packets on a network interface.

low risk

low riskCaptures all traffic including plaintext credentials and sensitive data.
⚠ Risks & cautions
  • Captures can contain passwords, tokens and personal data — capture the minimum, store files securely, delete them afterwards.
  • On busy interfaces an unfiltered capture can fill the disk; use filters, -c and -s.
What it does

tcpdump captures packets matching Berkeley Packet Filter (BPF) expressions. Requires root. -i specifies the interface. Write to .pcap files for analysis in Wireshark.

Common flags
FlagMeaning
-iNetwork interface to capture on (use 'any' for all)
-nDon't resolve hostnames or port names
-wWrite packets to a .pcap file
-cExit after capturing N packets
Examples
tcpdump -i eth0 -n port 80 -w /tmp/http.pcapCapture HTTP traffic to file for Wireshark analysis · explain & risk-check →
tcpdump -i any -n 'host 10.0.1.5 and port 5432'Capture PostgreSQL traffic to/from a specific host · explain & risk-check →
tcpdump -i eth0 -n -c 100 port 53Capture 100 DNS queries and exit · explain & risk-check →
Pro tip

Combine with -G and -W to auto-rotate capture files: `-G 60 -W 10` keeps 10 files of 60 seconds each.
