tee

Write to stdout and one or more files simultaneously.

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskCreates or overwrites files; use -a to append.
⚠ Risks & cautions
  • `tee file` truncates the file first — use -a to append.
  • With sudo: `cmd | sudo tee /etc/file` overwrites the whole file; back it up first.
What it does

tee reads from stdin and writes to both stdout and specified files simultaneously — splitting the pipeline. Essential when you want to log output while still piping it to another command.

Common flags
FlagMeaning
-a --appendAppend to files instead of overwriting
-i --ignore-interruptsIgnore interrupt signals

Pro tip

Use `sudo tee` instead of `sudo echo >` when writing to privileged files — `sudo echo >` doesn't work because redirection happens in the user shell, not as root.
