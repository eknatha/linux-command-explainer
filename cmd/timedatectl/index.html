⚠ Risks & cautions
  • `set-time`/`set-ntp false` changes the system clock behaviour — time jumps break TLS, Kerberos, databases and log correlation.
What it does

timedatectl is the systemd tool for managing system time. Shows current time, hardware clock, NTP sync status, and timezone. Used to set timezone for servers and verify NTP is active — critical for distributed systems and log correlation.

Common flags
FlagMeaning
set-timezoneSet timezone (e.g., Asia/Kolkata)
set-ntpEnable/disable NTP sync (true/false)
list-timezonesList all available timezones

Pro tip

Always verify `NTP synchronized: yes` on new servers before deploying distributed applications — unsynchronized clocks cause mysterious TLS errors and log correlation failures.
