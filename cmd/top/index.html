What it does

top provides a live display sorted by CPU usage. Press M to sort by memory, k to kill a process, q to quit. -b runs batch mode for scripting.

Common flags
FlagMeaning
-b --batchNon-interactive batch mode for scripts
-nNumber of iterations before exiting
-pMonitor specific PIDs only
-uShow processes for a specific user
Examples
top -bn1 | head -20Capture a single top snapshot for logging · explain & risk-check →
top -u www-dataMonitor only web server user processes · explain & risk-check →
Pro tip
