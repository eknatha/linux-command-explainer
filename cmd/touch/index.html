touch

Create an empty file or update timestamps

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskOnly creates files or changes timestamps.
⚠ Risks & cautions
  • Changing mtimes can confuse backups, rsync and build systems that rely on timestamps.
What it does

Creates the file if it does not exist, otherwise updates its modification time. Often used to create placeholders or reset mtime for make/rsync.

Common flags
FlagMeaning
-cDo not create missing files
-tSet a specific timestamp [[CC]YY]MMDDhhmm
-rCopy timestamps from another file
Examples
