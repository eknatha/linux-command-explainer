tput

Query and initialize terminal capabilities for scripting.

low riskRead-only terminal queries; terminal writes are temporary.
What it does

tput queries the terminal database (terminfo) to retrieve capabilities like terminal dimensions, cursor control codes, and color codes. Used in scripts to produce colored output, move the cursor, and check terminal dimensions portably.

Pro tip

Define colors with tput in scripts: `RED=$(tput setaf 1); NC=$(tput sgr0); echo "${RED}ERROR${NC}: msg"` — more portable than hardcoding ANSI escape codes.
