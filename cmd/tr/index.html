tr

Translate, squeeze, or delete characters in text streams.

What it does

tr translates or transforms characters — replacing, deleting, or squeezing repeated characters. Only works on stdin/stdout, not files directly. Frequently used for case conversion, removing unwanted characters, and cleaning data.

Common flags
FlagMeaning
-d --deleteDelete specified characters
-s --squeeze-repeatsSqueeze repeated characters to one
-c --complementUse complement of the character set
Examples

echo 'a b c' | tr -s ' 'Squeeze multiple spaces to one · explain & risk-check →
Pro tip

Use `tr -d '\r'` to fix Windows line endings in scripts cloned on Linux — a common cause of 'bad interpreter' errors.
