traceroute

Trace the network path to a host, hop by hop.

⚠ Risks & cautions
  • Probes many hosts along the path; some networks treat it as scanning.
What it does

traceroute sends packets with incrementing TTL values to discover each router hop between source and destination. Reveals routing paths, identifies where packets are dropped, and measures latency at each hop — essential for network troubleshooting.

Common flags
FlagMeaning
-n --numericDon't resolve hostnames (faster)
-T --tcpUse TCP SYN probes (bypasses ICMP blocks)
-p --portDestination port for TCP/UDP probes
-m --max-hopsMaximum number of hops

Pro tip

Use `traceroute -T -p 443` when ICMP is blocked — TCP SYN probes on the target port actually follow the production traffic path and bypass ICMP-blocking firewalls.
