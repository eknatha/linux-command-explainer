trap

Execute commands when the shell receives signals or exits.

low riskMisuse can suppress error signals and mask failures.
⚠ Risks & cautions
  • A wrong trap on EXIT/ERR can hide failures or run cleanup that deletes the wrong directory — quote and validate variables used in traps.
What it does

trap registers commands to run when specific signals are received (INT, TERM, EXIT, ERR). Critical for cleanup logic: removing temp files, sending alerts on failure, and ensuring safe teardown of resources when a script exits.

Examples
trap 'rm -f /tmp/mytemp.*' EXITClean up temp files on any exit · explain & risk-check →
trap 'echo "ERROR at line $LINENO"' ERRReport error line number on failure · explain & risk-check →
trap 'echo Interrupted; exit 1' INT TERMHandle Ctrl+C gracefully · explain & risk-check →
trap '' SIGPIPEIgnore broken pipe signals (common in pipelines) · explain & risk-check →
Pro tip

Use `trap 'cleanup' EXIT` instead of duplicating cleanup at every exit point — EXIT fires on all exits (normal, error, signal), so one trap covers all cases.
