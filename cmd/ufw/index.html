high riskEnabling ufw without allowing SSH will lock out remote access.
⚠ Risks & cautions
  • Run `ufw allow OpenSSH` (or your SSH port) BEFORE `ufw enable`.
  • `ufw reset` deletes all rules.
  • Docker-published ports bypass ufw unless configured.
Safer / dry-run alternatives
ufw allow OpenSSH && ufw status verboseAllow SSH first, then verify.
What it does

ufw (Uncomplicated Firewall) provides a simpler interface to iptables, widely used on Ubuntu and Debian systems. Rules are written in plain English (allow/deny + port/service). Always allow SSH before enabling ufw to avoid self-lockout.

Pro tip

On fresh Ubuntu servers, run `ufw allow ssh && ufw allow 443/tcp && ufw enable` in a single SSH session — if SSH fails, the session stays open and you can fix it.
