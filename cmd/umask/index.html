umask

Set default permissions mask for newly created files and directories.

low risk

low riskAffects only new files; doesn't change existing ones.
What it does

umask defines which permission bits are removed from new files/directories. The default umask 022 means files are created 644 (666-022) and directories 755 (777-022). A stricter umask 027 gives 640/750 — better for multi-user servers.

Pro tip

Set umask 027 in /etc/profile.d/ for service accounts on production servers — prevents world-readable files from being created accidentally.
