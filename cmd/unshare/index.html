unshare

Run a program with some namespaces unshared from the parent.

medium risk

medium riskCan create isolated environments that are hard to clean up.
⚠ Risks & cautions
  • Creates namespaces that persist while any process uses them — hard to clean up if forgotten.
  • `unshare -r` maps you to root inside a user namespace, which widens the kernel attack surface.
What it does

unshare creates new namespaces (network, PID, mount, user, UTS) and runs a command in them, isolated from the parent. Used to understand container internals, test namespace isolation, and create lightweight sandboxes without full container runtime.

Common flags
FlagMeaning
--netCreate new network namespace
--pidCreate new PID namespace
--mountCreate new mount namespace
--userCreate new user namespace (unprivileged)
--forkFork before executing command
Examples

Pro tip

Use `unshare --net bash` to test how your app behaves with no network — quickly reveals hardcoded DNS lookups or network dependencies you didn't know existed.
