updatedb

Rebuild the locate database

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskScans the entire filesystem and causes noticeable disk I/O.
⚠ Risks & cautions
  • Heavy I/O on large or network filesystems — avoid during peak hours on production hosts.
  • The database may expose the names of files other users cannot read on some systems; check mlocate/plocate permissions.
What it does

Walks the filesystem and rewrites the database used by locate. Normally run from cron daily.
