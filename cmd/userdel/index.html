userdel

Delete a user account

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskRemoves the account; with -r also its home directory and mail.
⚠ Risks & cautions
  • Back up the home directory first: tar -czf alice-home.tgz /home/alice.
  • Files owned by the old UID remain and could be re-assigned to a new user with the same UID.
  • Check running processes and crontabs of the user first.
Safer / dry-run alternatives
passwd -l <user> && chage -E0 <user>Lock instead of delete
tar -czf <user>-home.tgz /home/<user>Back up before deleting
find / -user <user> -ls 2>/dev/nullFind files owned by the user
What it does

Deletes a user from /etc/passwd and /etc/shadow.

Common flags
FlagMeaning
-rRemove home directory and mail spool⚠ Permanently deletes the user’s files.
-fForce removal⚠ Even if the user is logged in.
