usermod

Modify a user account

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskChanging UID/group/home incorrectly breaks logins and file ownership.
⚠ Risks & cautions
  • `usermod -G group user` without -a replaces ALL supplementary groups — you can remove sudo access or lock someone out.
  • Adding users to sudo, wheel or docker grants root-equivalent access.
  • Don’t change a logged-in user’s UID/home without planning the migration.
Safer / dry-run alternatives
id <user>Record current groups first
usermod -aG <group> <user>Always use -a with -G
What it does

Edits account attributes: groups, shell, home, login name, lock state.

Common flags
FlagMeaning
-aGAppend to groups (always use -a with -G)⚠ Without -a the user is REMOVED from all other groups.
-LLock account
-UUnlock account
-sLogin shell
-dHome directory (use -m to move)
-lChange login name
