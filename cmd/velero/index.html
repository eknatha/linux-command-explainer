velero

Backup, restore, and migrate Kubernetes cluster resources and persistent volumes.

⚠ Risks & cautions
  • `velero restore` can overwrite existing resources and PVC data.
  • Check `velero backup describe` / `logs` and restore into a test namespace first.
  • Backups do not include volume data unless snapshots or file-system backup are configured.
What it does

Velero backs up Kubernetes cluster state and persistent volume data to object storage (S3, GCS, Azure Blob). Enables disaster recovery, cluster migration, and namespace-level restore. Backups include all K8s objects and optionally PV snapshots.

Pro tip

Always test restores, not just backups. Schedule a monthly `velero restore create --from-backup latest --include-namespaces test` in a non-prod cluster to verify backup integrity.
