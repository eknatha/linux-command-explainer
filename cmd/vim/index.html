⚠ Risks & cautions
  • Use `sudoedit` instead of `sudo vim` so plugins and your config do not run as root.
  • Swap, backup and viminfo files can contain secrets — use `vim -n` or `set noswapfile` for sensitive files.
  • Editing live config directly can break services: test (nginx -t, visudo -c) before reloading.
What it does

Modal text editor. Esc to command mode, :wq to save and quit, :q! to quit without saving.
