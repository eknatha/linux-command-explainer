visudo

Safely edit sudoers

high riskMistakes can remove everyone’s sudo access.
⚠ Risks & cautions
  • Always keep a second root session open while editing.
  • NOPASSWD: ALL entries grant unrestricted root without a password — limit to specific commands.
  • A syntax error can disable sudo entirely if edited with a normal editor.
Safer / dry-run alternatives
visudo -cValidate after editing
visudo -f /etc/sudoers.d/<name>Use drop-in files
What it does

Locks and syntax-checks /etc/sudoers before saving.

Common flags
FlagMeaning
-cCheck syntax only
-fEdit a specific file (e.g. /etc/sudoers.d/x)
