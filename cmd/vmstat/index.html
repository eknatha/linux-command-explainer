vmstat

Report virtual memory, CPU, and I/O statistics.

What it does

vmstat provides a snapshot or continuous stream of system resource statistics: processes, memory, swap, block I/O, and CPU time. Ideal for diagnosing high CPU wait (wa column) indicating I/O bottlenecks, or high swap usage.

Common flags
FlagMeaning
-a --activeShow active/inactive memory
-s --statsPrint memory event statistics table
-d --diskShow disk statistics

Pro tip

Watch the 'wa' (I/O wait) column in `vmstat 1` — consistently above 10-15% indicates disk is the bottleneck, not CPU. This is often misread as a CPU problem.
