watch

Repeatedly execute a command at intervals and display output.

low risk

low riskRuns commands repeatedly; avoid watch on write operations.
⚠ Risks & cautions
  • `watch` re-runs the command every interval — with kubectl, aws or API calls this can hammer the target or hit rate limits.
  • Do not watch destructive commands.
What it does

watch runs a command every N seconds (default 2) and displays its output full-screen, highlighting changes. Perfect for monitoring dynamic state like pod counts, resource usage, or deployment rollouts without writing a custom loop.

Common flags
FlagMeaning
-n --intervalSet update interval in seconds
-d --differencesHighlight changes since last update
-g --chgexitExit when output changes
-e --errexitFreeze on command error

Pro tip

Use `watch -d` during rolling deployments to instantly spot when pod statuses change — the highlighting makes it obvious without having to scan all rows manually.
