What it does

wc (word count) counts newlines, words, characters, and bytes in files or stdin. Invaluable for quick data validation — checking how many records are in a file, confirming a log has expected line counts, or measuring output size.

Common flags
FlagMeaning
-l --linesCount lines only
-w --wordsCount words only
-c --bytesCount bytes only
-m --charsCount characters only

Pro tip

Use `grep -c 'pattern' file` instead of `grep 'pattern' file | wc -l` — it's faster and more efficient for counting matching lines.
