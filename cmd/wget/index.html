wget

Download files from the web non-interactively.

low risk

interactive breakdown — edit the command and press Explain
$ 
low riskDownloads files; piping output to shell can execute arbitrary code.
⚠ Risks & cautions
  • `wget -O- … | sh` runs unseen remote code.
  • --no-check-certificate disables TLS verification; downloads overwrite existing files with the same name unless -nc is used.
What it does

wget specializes in downloading and supports recursive website mirroring. Unlike curl it saves to a file by default. -c resumes interrupted downloads. -q suppresses output for scripts.

Common flags
FlagMeaning
-OSave to a specific filename
-c --continueResume a partially downloaded file
-q --quietSilent mode
-r --recursiveDownload recursively (website mirroring)
-P --directory-prefixSet download directory
