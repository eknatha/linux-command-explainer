What it does

whereis locates binary, source code, and manual page files for a given command, searching standard system directories (not just PATH). More comprehensive than which but less precise for custom installations.

Common flags
FlagMeaning
-b --binarySearch for binary only
-m --manualSearch for man pages only
-s --sourceSearch for source only
Examples

Pro tip

Use `whereis -b cmd` in automation scripts to check if a binary exists before using it — more reliable than `which` across different distros.
