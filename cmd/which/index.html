What it does

which searches PATH directories for the specified command and prints the full path. Essential for diagnosing 'command not found' errors, verifying which version of a tool is active, and understanding PATH resolution order.

Common flags
FlagMeaning
-a --allPrint all matching paths, not just the first
Examples

Pro tip

Use `which -a <cmd>` when debugging version conflicts — it reveals all installed copies so you know exactly which one your PATH resolves to first.
