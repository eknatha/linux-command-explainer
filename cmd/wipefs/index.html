high riskRemoves filesystem/RAID/LVM signatures; data becomes unreachable.
⚠ Risks & cautions
  • Verify the device with lsblk; use -n first.
  • Back up signatures: wipefs -b …
Safer / dry-run alternatives
wipefs -n -a <device>Dry run first
wipefs <device>List signatures read-only
What it does

Lists or erases signatures from block devices.

Common flags
FlagMeaning
-nDry run
-aErase all signatures⚠ Makes the disk look empty.
