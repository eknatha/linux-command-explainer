high riskCan discard metadata and data; -L destroys the log.
⚠ Risks & cautions
  • Mount/unmount once to replay the log before using -L.
  • Back up (xfs_metadump or image) before repairs.
Safer / dry-run alternatives
xfs_repair -n <device>Check without modifying
What it does

Repairs XFS filesystems, which must be unmounted. -n only checks.

Common flags
FlagMeaning
-nCheck only, no changes
-LZero the log (data loss)⚠ Discards the metadata log.
