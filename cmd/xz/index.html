xz

High-ratio compression using the XZ/LZMA algorithm.

What it does

xz provides high compression ratios using the LZMA2 algorithm — better compression than gzip at the cost of more CPU and memory. Widely used for distributing Linux kernel tarballs and large datasets. Works like gzip in its pipeline behavior.

Common flags
FlagMeaning
-d --decompressDecompress
-k --keepKeep input file after compression

--threads --threadsNumber of threads (0 = all CPUs)

Pro tip

Use `xz -T 0` to enable multi-threaded compression on large files — xz is single-threaded by default and can be extremely slow without this flag.
