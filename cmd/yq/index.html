yq

Command-line YAML/JSON/XML processor (like jq but for YAML).

low riskRead-only unless -i flag is used (in-place edit).
⚠ Risks & cautions
  • `yq -i` edits files in place — keep a backup or use version control.
  • Different yq implementations (mikefarah vs python-yq) have different syntax.
What it does

yq processes YAML, JSON, XML, and TOML files with a jq-compatible syntax. Invaluable for editing Kubernetes manifests, Helm values files, and CI config files without breaking structure. The -i flag edits files in-place.

Common flags
FlagMeaning
-i --inplaceEdit file in-place
-r --rawOutput raw strings
-o --output-formatOutput format: yaml, json, props

Pro tip

Use yq to patch image tags in manifests during CI: `yq -i '.spec.template.spec.containers[0].image = "app:v1.2.3"' deploy.yaml` — cleaner than sed on YAML.
