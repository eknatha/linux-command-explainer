What it does

Decompresses gzip files to stdout without touching the file — great for rotated logs.

Examples
zcat /var/log/syslog.2.gz | grep -i errorSearch a rotated log · explain & risk-check →
zcat -f file.gz file.txtWorks with plain files too · explain & risk-check →
