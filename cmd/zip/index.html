zip

Create ZIP archives

low risk

interactive breakdown — edit the command and press Explain

low riskCreates a new file; can overwrite an existing archive name.
⚠ Risks & cautions
  • `zip -e` uses weak encryption and the password is easy to leak via shell history — use gpg or age for sensitive data.
  • Existing archives are updated, not replaced — delete the old zip first if you want a clean archive.
What it does

Packs files into a .zip archive (portable to Windows/macOS).

Common flags
FlagMeaning
-rRecurse into directories
-eEncrypt with a password (weak legacy encryption)
-xExclude patterns
-9Best compression
