What it does

zstd (Zstandard) offers near-gzip speed with compression ratios approaching xz. The --fast flag prioritizes speed; higher -N levels improve ratio. Now the default compression for Linux kernel packages and increasingly common in DevOps tooling.

Common flags
FlagMeaning
-d --decompressDecompress
-k --keepKeep source file
-NCompression level 1-19 (default: 3)
--fastUltra-fast compression (sacrifices ratio)
-T --threadsNumber of threads

Pro tip

For backup pipelines, zstd is the modern choice: `tar c /data | zstd -T 0 -9 -o backup.tar.zst` — 3-4x faster than xz with only slightly worse compression.
