⚠ Risks & cautions
  • Test rules at runtime first; persist with --runtime-to-permanent once verified.
  • Never remove the ssh service from the active zone on a remote host.
  • Rich rules are evaluated in order — a broad reject can shadow later accepts.

What it does

firewall-cmd is the command-line client for firewalld. It supports rich rules for complex filtering (source IP + port + protocol), port forwarding, masquerading, and IP sets. Rich rules give you iptables-level power with firewalld's zone management.

Common flags
FlagMeaning

--add-masqueradeEnable IP masquerading (NAT)

Pro tip

Use rich rules for IP-based allow/deny instead of iptables — they integrate with zones and persist cleanly. Test with `--timeout=30` to auto-revert if you accidentally lock yourself out.
