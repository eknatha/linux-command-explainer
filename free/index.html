free

Display total, used, and available system memory.

What it does

free shows physical memory and swap usage. The 'available' column (not 'free') is what matters — it includes reclaimable cache and is what the kernel reports as usable for new processes. Buffers and cache are not 'wasted' memory.

Common flags
FlagMeaning
-h --humanPrint human-readable sizes (MB/GB)
-s --secondsContinuously update at interval
-t --totalShow grand total row
Examples

Pro tip

The 'available' column is the only one that matters for capacity planning — ignore 'free'. Linux aggressively uses RAM for cache; that's normal and good.
