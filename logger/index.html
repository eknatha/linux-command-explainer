logger

Send messages to the system log (syslog/journald).

low risk

low riskWrites to system log; flooding can fill log storage.
⚠ Risks & cautions
  • Do not log secrets — syslog is readable by many users and often shipped to central systems.
What it does

logger writes messages to the system journal or syslog. Used in scripts to emit structured log entries that appear in journalctl alongside system logs — crucial for script audit trails and integration with centralized logging.

Common flags
FlagMeaning
-t --tagAdd a tag/identifier to messages
-p --prioritySet message priority (e.g., user.error)
-s --stderrAlso print to stderr
-n --serverSend to remote syslog server
Examples
logger -t deploy 'Deployment v1.2.3 started by ec2-user'Log a tagged deployment event · explain & risk-check →

Pro tip

Add `logger -t $(basename $0) "Starting: $0 $*"` to the top of every admin script — creates an automatic audit trail in journald for all script executions.
