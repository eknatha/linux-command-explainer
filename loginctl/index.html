loginctl

Manage login sessions

high risk

interactive breakdown — edit the command and press Explain
$ 
high riskCan terminate sessions and users, including your own.
⚠ Risks & cautions
  • terminate-user/terminate-session kills all that user’s processes — including unsaved work and your own SSH session.
  • enable-linger lets a user keep processes running with no login; review who has it.
Safer / dry-run alternatives
loginctl list-sessionsCheck which session is which first
loginctl show-session <id>Inspect before terminating
What it does

Query and control systemd-logind: list sessions, lock/terminate sessions, enable linger.

Common flags
FlagMeaning
list-sessionsShow sessions
terminate-sessionEnd a session
terminate-userEnd all of a user’s sessions
enable-lingerLet user services run without a login
