pgrep

Find process IDs by name or other attributes.

What it does

pgrep finds PIDs matching name patterns or other criteria without parsing ps output. Returns just PIDs, making it ideal for scripting. pkill (its sibling) sends signals to matched processes. The -a flag includes the full command line.

Common flags
FlagMeaning
-a --list-fullPrint full command line
-u --euidMatch by effective user
-f --fullMatch against full command line
-l --list-nameList PID and name
-x --exactExact name match only

Pro tip

Use `pgrep -f 'pattern'` instead of `ps aux | grep | awk` — cleaner, no accidental self-match, and returns just PIDs for direct use in commands.
