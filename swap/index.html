swap (advanced)

Manage swap space on Linux systems.

medium risk

medium riskDisabling swap on memory-constrained systems triggers OOM.
⚠ Risks & cautions
  • Disabling swap on a memory-constrained host can trigger the OOM killer.
  • swapoff has to move pages back into RAM and can take a long time on a busy system.
  • Persist swap in /etc/fstab or it disappears at reboot.
What it does

Linux swap (managed via swapon/swapoff and /etc/fstab) extends virtual memory using disk space. On cloud instances, swap files are often preferred over swap partitions. Kubernetes nodes should have swap disabled (swapoff -a) for proper resource accounting.

Pro tip

Set `vm.swappiness=10` on database servers — reduces aggressive swap usage that causes latency spikes. On Kubernetes nodes, set `swappiness=0` or disable swap entirely.
