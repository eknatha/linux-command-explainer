tmux

Terminal multiplexer: manage multiple terminal sessions in one window.

low risk

low riskSessions persist independently; easy to lose work if confused.
⚠ Risks & cautions
  • Detached sessions keep running (and keep any secrets or credentials in scrollback) — close them when finished.
What it does

tmux creates persistent terminal sessions with multiple windows and panes. Sessions survive SSH disconnects — critical for long-running operations. Supports session sharing for pair programming and detach/reattach workflows.

Examples
tmux new -s deployCreate named session 'deploy' · explain & risk-check →
tmux attach -t deployReattach to 'deploy' session · explain & risk-check →
tmux lsList all active sessions · explain & risk-check →
tmux kill-session -t deployKill a specific session · explain & risk-check →
Pro tip

Essential keybindings: Ctrl+b d (detach), Ctrl+b c (new window), Ctrl+b % (split vertical), Ctrl+b " (split horizontal). Run long operations in tmux — they survive SSH drops.
