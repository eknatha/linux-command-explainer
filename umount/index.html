umount

Unmount filesystems

medium risk

interactive breakdown — edit the command and press Explain
$ 
medium riskUnmounting a busy filesystem can break services; -l/-f leave stale handles or lose data.
⚠ Risks & cautions
  • Check usage with fuser -vm / lsof +D first.
  • Lazy unmount hides problems rather than solving them.
Safer / dry-run alternatives
fuser -vm <mountpoint>Find processes using the mount
findmnt <mountpoint>Confirm what is mounted there
What it does

Detaches a filesystem. Fails if files are open (use lsof/fuser to find them).

Common flags
FlagMeaning
-lLazy unmount: detach now, clean up later⚠ Processes keep stale handles.
-fForce (NFS)⚠ May lose in-flight data.
-RRecursive
